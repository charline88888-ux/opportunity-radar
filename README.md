# 机会雷达 Opportunity Radar · 全球商机扫描器（本地个人版）

> 用「人性需求信号 + 文化差异信号」持续发现全世界的赚钱信息差，按 **日 / 周 / 月 / 年** 榜单交付，并为每个机会强制回答 **商业驱动七问**。
> 本地优先（Local-first）：数据与页面全部在你自己的电脑上，双击 HTML 即可用，不上传云端。
>
> **当前版本：v0.1.0（2026-10-22）**　｜　数据版本：data-v0.1.0　｜　冻结产物：[`releases/v0.1.0/`](releases/v0.1.0/)　｜　版本历史见文末。

## 现在能做什么（v0.1.0）

- **指挥台**：今日新信号、四大榜单速览、评分分布、区域/行业/人性需求全景图。
- **排行榜**：日 / 周 / 月 / 年四个窗口 + 14 个行业板块 + 信息差类型筛选 + 热度与排名变化。
- **机会详情**：七问全答、10 维评分雷达、ROI 与回本周期、证据链、7 天验证动作、证伪条件、风险与合规。
- **扫描室**：人性需求 × 信号类型矩阵、信息差类型流向图、12 个扫描剧本（可直接照做）、数据源健康度。
- **方法论**：评分权重可拖动实时重排、七问框架、神经递质与情绪映射、信息差类型学、全球商业日历。
- **数据源矩阵**：60+ 平台分类、访问方式、频率、成本、合规等级、价值评分。
- **版本隔离**：`releases/vX.Y.Z/` 每次升级独立冻结，旧版本永不修改，可随时回滚。

## 快速开始

1. 直接打开冻结版页面（无需安装、无需联网）：
   `releases/v0.1.0/dist/index.html`
2. 本地跑扫描流水线（重新生成榜单数据，Python 3.11，仅标准库）：
   ```powershell
   python scanner/pipeline.py --all
   ```
3. 前端开发与重新构建：
   ```powershell
   cd app
   pnpm install
   pnpm dev      # 本地开发
   pnpm build    # 产物在 app/dist
   ```
4. 打新版本（冻结到 releases/，不污染旧版本）：
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts/release.ps1 -Version v0.2.0
   ```
