> **每天扫描全球公开信号 → 系统评估商机 → 自动入榜（日 / 周 / 月 / 年）。**

## 现在能做什么（v1.0.0 核心回归）

- **每天自动扫描**：101 个自动源 / 168 个平台目录 / 覆盖 11 区域；GitHub Actions 每天 06:30（北京时间）执行 fetch → 评估 → 榜单 → 上线。
- **系统评估商机**：候选自动评分（10 维启发式 + 系统评估检查），标注 high / medium / low 与分数；不需要人工验证。
- **商机榜（唯一榜单）**：日 / 周 / 月 / 年四窗口，自动候选全部入榜 + 精选标签；中文标题，原文可对照。
- **候选详情**：七问自动草稿、证据来源、ROI 估算、评分维度、免责声明。
- **精选机会**：80 条人工整理的高质量机会卡（七问 + 证据链），也可在榜中筛选查看。
- **扫描室**：源健康度、采集漏斗（尝试/成功/失败、原始→去重→新增→相关）、未覆盖平台。
- **方法论 / 数据源矩阵 / 商业日历 / 关于**：评分体系、168 平台目录、33 个商业节点、版本说明。

已移除（v1.0.0）：本地控制台、验证/实验、校准、年度报告、个人画像、预警中心、数据包、登录自启等一切非核心功能。

## 快速开始

### 方式 A：直接打开（无需安装/联网）
双击 `releases/v1.0.0/dist/index.html`（单文件，离线可用）。

### 方式 B：在线
打开 https://charline88888-ux.github.io/opportunity-radar/ （每天自动刷新数据；历史版本在 `/vX.Y.Z/`）。

### 方式 C：本地重新扫描（可选）
```powershell
python scanner/pipeline.py --fetch --as-of (Get-Date -Format yyyy-MM-dd) --fetch-limit 160
python scanner/pipeline.py --all --as-of (Get-Date -Format yyyy-MM-dd)
python scanner/validate.py
cd app; pnpm install --frozen-lockfile; pnpm build
```
然后打开 `app/dist/index.html`，或按发布流程生成新版本。

## 核心原则

1. **只做发现**：系统负责扫描、评估、入榜；不验证个人能否赚钱。
2. **无人工门禁**：自动候选全部入榜，精选只是标签。
3. **可追溯**：每条候选带来源、证据链接、评分与系统评估等级。
4. **本地优先**：数据与页面在本地；线上仅为只读展示与每日自动更新。
