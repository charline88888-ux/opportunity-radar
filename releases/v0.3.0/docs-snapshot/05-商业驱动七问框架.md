# 05 商业驱动七问框架与标准化模板

> 版本：v0.1.0（对齐 `docs/12-数据契约与字段字典.md`，`seven_questions` 字段）
> 定位：本文件回答「一个机会到底怎么做」——用七个必答问题把「听起来不错」逼成「说得清楚、算得明白、做得下去」。
> 配套：`docs/03`（机会怎么发现）、`docs/04`（机会怎么打分）、`docs/12`（字段与枚举）。
> 硬约束：七问答案要写进 `opportunities.json` 的 `seven_questions`；本文件不新增字段、不改枚举、不改评分公式。

---

## 0. 定位与使用方式

### 0.1 为什么强制七问

一个机会如果只写「市场规模大、增长快、有需求」，它无法被执行，也无法被证伪。七问的作用是**把叙事拆成可操作的七个决策**：

| 问题 | 本质决策 | 答不上来的真实含义 |
|---|---|---|
| 流量怎么来 | 客户从哪来、成本多少 | 你还没有面对「没人知道你」的现实 |
| 赚什么钱 | 收谁的钱、收多少、占比多少 | 你还没想清楚谁付钱、为什么付 |
| 商业模式形态 | 价值链怎么组织、怎么交付 | 你只有一个点子，没有一条链路 |
| 投入回报与时间周期 | 要投多少、多久回本、现金流怎样 | 你没算过账，或者算不过来 |
| 适合人群 | 谁适合做、谁千万别做 | 你没评估过执行者的约束 |
| 驱动类型 | 这个机会靠什么力量推动 | 你不知道它为什么现在成立 |
| 壁垒与前置条件 | 凭什么活下来、需要什么条件 | 你没有护城河，也没有入场券 |

**七问的顺序有逻辑**：先证明有人要（流量/钱），再证明能交付（模式/回报），再证明「是你」（人群/驱动），最后证明「能持续」（壁垒）。顺序颠倒（先想壁垒再想需求）是典型的自嗨。

### 0.2 七问与契约字段映射

docs/12 §4.3 规定的 `seven_questions` 共 7 个字段：

| 七问 | 契约字段 | 类型 | 写作要求 |
|---|---|---|---|
| 第一问 流量怎么来 | `traffic` | string | 具体渠道 + 内容形式 + 前 100 个客户从哪来 |
| 第二问 赚什么钱 | `money` | string | 售卖实物/服务/信息/订阅/佣金/广告 + 各自占比与客单 |
| 第三问 商业模式形态 | `model` | string | 一句模式 + 价值链条 + 交付方式 |
| 第四问 投入回报与时间周期 | `roi` | string | 启动资金、回本周期、月收入区间、毛利、现金流特征 |
| 第五问 适合人群 | `audience` | string | 什么资源/技能/语言/身份的人最合适，不适合谁 |
| 第六问 驱动类型 | `drivers` | enum[] | 7 个驱动 id 中选 1–3 个（同时写入机会对象顶层 `seven_questions.drivers`） |
| 第七问 壁垒与前置条件 | `moat` | string | 壁垒类型 + 需要什么条件；没有壁垒要如实说 |

> 注意：`seven_questions` 里**没有**单独的结构化 ROI 对象——`roi` 字段在机会对象顶层（docs/12 §4.4），七问里的 `roi` 是文字版。填写时两者必须一致（数值区间、回本周期、毛利）。

### 0.3 七问合格线总表

| 问 | 不合格 | 合格（可入库） | 优秀（可行动） |
|---|---|---|---|
| 流量 | 「靠平台推荐」「做内容引流」 | 写清 2 个具体渠道 + 内容形式 + 首批客户来源 | 给出渠道优先级、预估 CAC、前 100 客户的具体动作与时间 |
| 钱 | 「卖货赚钱」 | 写清收入类型、客单、毛利、收入占比 | 给出收入结构表、复购/加购设计、盈亏平衡点 |
| 模式 | 「开个店/做个品牌」 | 写清模式 + 价值链 3–5 环 + 交付方式 | 画出链条、标出自己掌控的环节、标出外包/合作方 |
| 回报 | 「成本低、利润高」 | 给启动资金、回本周期、月收入区间、毛利 | 给三档情景（保守/基准/乐观）+ 现金流特征 + 最大损失 |
| 人群 | 「适合所有人」「适合小白」 | 写清最适合的 2–3 类人 + 明确不适合的人 | 写清能力/资源/身份门槛、替代人选、失败退出路径 |
| 驱动 | 「因为市场大」 | 从 7 个驱动 id 中选 1–3 个并解释 | 说明驱动强度、持续性、与其他驱动的组合 |
| 壁垒 | 「没有壁垒」「靠努力」 | 说出 1 种壁垒或诚实说「窗口期套利」 | 给出壁垒建立路径、前置条件、被复制的概率与时间 |

### 0.4 七问的底层逻辑链

```
需求真实性（第一问 + 第二问）
  → 交付可行性（第三问）
    → 经济可行性（第四问）
      → 执行者匹配（第五问）
        → 时机归因（第六问）
          → 持续性（第七问）
```

**判定原则**：
- 七问**全部答完**才算机会；（docs/12 V04：7 个字段齐全、非空、不含占位词）
- 任何一问只能写占位词 = 这个机会还没准备好，留在草稿区，不进机会库；
- 七问不是一次写完的文档，而是**每轮验证后更新**的活文档（版本记录写在 `data/CHANGELOG.md`）。

### 0.5 谁在什么时候答

| 阶段 | 谁答 | 深度 | 产出 |
|---|---|---|---|
| 扫描阶段（docs/03 步骤 1–2） | 扫描者 | 只答第一、二问的草稿 | 假设卡 |
| 入库阶段（机会库） | 方法负责人 | 七问全答（合格线） | `seven_questions` 字段 |
| 验证阶段（7 天） | 执行者 | 用真实数据修正第一、二、四问 | 验证记录 |
| 行动阶段 | 执行者 | 每月更新第四、七问 | 复盘 |
| 评审阶段 | 红队 | 抽查七问一致性与真实性 | 审计记录 |

### 0.6 答不上来时的处理

| 情况 | 处理 |
|---|---|
| 第一/二问答不上 | 机会不成立，退回 docs/03 步骤 2–4，不要写七问 |
| 第三/四问答不上 | 机会存在但你不会做/算不过来，降级为「观察」，留在年榜 |
| 第五问答不上 | 说明你没想清楚「谁来做」，先找执行者再入库 |
| 第六问答不上 | 说明「为什么现在」不成立，回 docs/04 重评 `timing` |
| 第七问答不上 | 可以入库，但必须诚实写「窗口期套利，无长期壁垒」，并在 `kill_criteria` 写「窗口关闭即退出」 |

## 1. 七问逐问详解

> 每问统一结构：必答结构 → 信息从哪查 → 判断标准 → 常见错误 → 追问清单 → 两个行业的示范答案（实物跨境 A = 宠物离世纪念玻璃；服务/信息类 B = 中东宗教教育内容本地化）。

### 1.1 第一问：流量怎么来

**要回答的三个子问题**：
1. **渠道**：客户在哪个平台/场景里？你从哪个入口触达？
2. **内容**：用什么内容形式让客户停下来、相信你、点进来？
3. **前 100 个客户**：不是「以后怎么放大」，而是「第一批 100 单具体从哪来、多久拿到、花多少钱」。

**必答结构**：

| 要素 | 必须写清 | 示例 |
|---|---|---|
| 主渠道（1–2 个） | 平台名 + 具体入口（搜索/推荐/群组/线下） | Etsy 搜索 + Pinterest 图片搜索 |
| 内容形式 | 图文/短视频/直播/长文/工具 | 制作过程视频、场景对比图、真实故事 |
| 搜索词/话题 | 客户实际会搜的词 | "pet memorial glass"、"cremation glass"、"pet loss gift" |
| 前 100 客户来源 | 具体动作 + 时间 | 前 30 单 Etsy 自然搜索；后 70 单 5 个宠物殡葬博主 + 3 个 Facebook 群 |
| 获客成本上限 | CAC 上限（占毛利比例） | CAC ≤ $20（毛利 $100+） |
| 可复制性 | 这个渠道能否重复、放大 | Etsy SEO 可复制；KOL 合作需持续谈 |

**信息从哪查**：
- 平台搜索下拉/相关搜索（最真实的客户词）；
- Etsy/Amazon 关键词工具、Google Keyword Planner、Ahrefs/SEMrush（可选）、平台广告后台的推荐词；
- 竞品的内容形式与更新频率（看他们靠什么拿流量）；
- Reddit/小红书/本地社群的高赞内容（哪种叙事有效）；
- 平台官方活动日历（大促/节日流量）。

**判断标准**：

| 等级 | 标准 |
|---|---|
| 不合格 | 只写「靠平台推荐」「做内容」「投广告」；没有具体平台、搜索词、首批动作 |
| 合格 | 写清 1–2 个主渠道 + 内容形式 + 搜索词 + 前 100 客户来源 |
| 优秀 | 给出渠道优先级、预估 CAC、7 天可执行的首批动作、可复制的放大路径 |

**常见错误**：

| 错误 | 为什么错 | 怎么改 |
|---|---|---|
| 把「平台有流量」当「我能拿到流量」 | 平台流量属于头部，新账号冷启动难 | 写清新账号的冷启动路径 |
| 只写渠道不写内容 | 同样的平台，内容不同结果差 10 倍 | 写清 1 种能持续产出的内容形式 |
| 忽略「前 100 客户」 | 100 单之前没有自然流量 | 给出具体的人/群/博主名单获取方式 |
| 用「投广告」当答案 | 没有预算/CAC 测算 | 写出 CAC 上限与测试预算 |
| 忽略平台规则 | 违规内容/刷单封号 | 查平台规则，写合规获客方式 |

**追问清单**：
1. 你的客户现在在哪个平台搜什么词？
2. 你能持续产出哪种内容？一周几条？
3. 前 100 个客户，你打算从哪里、用什么话术、花多少钱拿到？
4. 如果主渠道被封/涨价，你的第二渠道是什么？

**示范答案 A（宠物纪念玻璃）**：

> 主渠道 Etsy 搜索 + Pinterest。Etsy 关键词 "pet memorial glass"、"cremation glass"、"pet loss gift"、"dog memorial gift"；Pinterest 发场景图（骨灰盒旁摆放、阳光下的玻璃、宠物照片对比）。内容：制作过程短视频（熔玻璃、封入毛发/骨灰替代物）、「为什么选择纪念玻璃」图文、真实客户故事（经授权、匿名）。前 100 单：前 30 单来自 Etsy 自然搜索（优化标题/标签/首图）；后 70 单靠 5 个宠物殡葬/宠物 loss 博主寄样合作 + 3 个 Facebook 宠物哀悼群的真实分享。CAC 上限 $20（客单 $180，毛利 $110）。7 天动作：上 10 个 listing、发 5 张 Pinterest 图、联系 5 个博主。

**示范答案 B（中东宗教教育内容本地化）**：

> 主渠道 LinkedIn 外呼 + 本地教育展会 + WhatsApp 家长/教师群。目标客户是海湾国家的伊斯兰教育出版商、私立学校、家庭学校家长。内容：阿拉伯语+英语双语案例页、免费样章（1 页教材本地化前后对比）、宗教学者背书短文。前 10 个 B2B 客户：从 5 家出版商（LinkedIn/官网表单）和 3 所私立学校（GESS Dubai 等教育展名单）切入；前 100 个 C 端客户：通过 3 个阿语家长 Telegram/WhatsApp 群和 2 个教育类 Instagram 账号分销数字练习册。CAC 对 B2B 不敏感（单客户年值 $2k–10k），C 端 CAC 目标 ≤$8。7 天动作：列出 30 个出版商/学校名单、发 10 封阿语+英语邮件、做 1 页样章。

### 1.2 第二问：赚什么钱

**要回答的三个子问题**：
1. **收入类型**：实物/服务/信息/订阅/佣金/广告，各占多少？
2. **客单与毛利**：一单收多少、成本多少、净赚多少？
3. **持续性**：一次性、复购、订阅、加购、向上销售？

**必答结构**：

| 要素 | 必须写清 | 示例 |
|---|---|---|
| 收入类型与占比 | 6 类收入各自占比 | 实物 85% + 加购 10% + 运费 5% |
| 客单价 | 主力 SKU 价格带 | $120–400 |
| 单件成本 | 货+运+平台费+支付费+退货 | $60–120 |
| 毛利 | 毛利率与毛利额 | 60–75%，$70–250 |
| 复购/加购 | 有没有、周期多长 | 加购纪念项链 $30–80；复购低 |
| 收入上限 | 单人/小团队月收入天花板 | $3k–10k/月 |

**信息从哪查**：
- 竞品定价与套餐（看他们卖什么组合）；
- 平台费用表（佣金/支付/广告）；
- 1688/Alibaba 报价 + 运费/关税；
- 目标市场支付习惯（分期/COD/订阅）；
- 同类卖家的公开访谈/评论（收入结构线索）。

**判断标准**：

| 等级 | 标准 |
|---|---|
| 不合格 | 只写「卖货赚钱」；无客单、无成本、无毛利 |
| 合格 | 写清收入类型、客单、毛利、收入占比 |
| 优秀 | 给出收入结构表、复购/加购设计、盈亏平衡点、三档收入情景 |

**常见错误**：

| 错误 | 为什么错 | 怎么改 |
|---|---|---|
| 把 GMV 当收入 | 平台流水不等于到手 | 算净收入（扣佣金/退款/运费） |
| 忽略隐性成本 | 退货、支付费、关税、客服时间 | 列全成本项，至少留 10% 缓冲 |
| 只做一次性生意 | 获客成本收不回 | 设计加购/复购/订阅 |
| 定价拍脑袋 | 要么亏、要么卖不动 | 用成本加成 + 竞品锚定 + 价值定价三法交叉 |
| 收入类型单一 | 抗风险差 | 设计 2 种以上收入（主+辅） |

**追问清单**：
1. 客户为什么付这个价，而不是买便宜的替代品？
2. 一单到手多少钱？扣掉所有成本还剩多少？
3. 客户会不会再买？多久买一次？
4. 除了卖货，还能卖什么（服务/信息/会员）？

**示范答案 A（宠物纪念玻璃）**：

> 收入结构：实物定制 85%（客单 $120–400，主力 $180）、加购 10%（纪念项链 $30–80、相框 $25–50）、运费 5%（$20–40 直邮）。单件成本 $60–120（玻璃工艺 $25–60 + 包装 $8–15 + 跨境运费 $20–35 + 平台佣金 6.5% + 支付 3% + 退货计提 5%），毛利 60–75%。复购天然低，靠加购与「周年纪念」二次触达。单人月收入上限约 $3k–8k（受产能限制）。盈亏平衡：月销 8–10 单覆盖固定成本。

**示范答案 B（中东宗教内容本地化）**：

> 收入结构：B2B 本地化服务 60%（按千字 $80–200 或按本 $800–4000）、宗教审校 25%（按项目 $200–1500）、数字练习册/课程 15%（$5–20/份，B2C 走量）。B2B 年框客户 40% 复购（教材每年更新）；C 端数字产品边际成本近零。毛利 60–75%（主要成本是审校专家费与获客时间）。单人+1 名兼职审校，月收入 $3k–15k；现金流受 B2B 账期影响（30–90 天），需预付或分期收款。

### 1.3 第三问：商业模式形态（价值链）

**要回答的三个子问题**：
1. **一句模式**：用一句话说清「谁—提供什么—怎么收钱」。
2. **价值链**：从原料/内容到客户手里，经过哪 5–7 个环节？你掌控哪几个？
3. **交付方式**：实物/数字/服务/混合？谁交付、多久、成本多少？

**必答结构**：

| 要素 | 必须写清 | 示例 |
|---|---|---|
| 模式 id | 12 个商业模式之一或组合 | `dtc` + `marketplace` |
| 一句话模式 | 谁+什么+怎么收钱 | 为欧美宠物主提供定制纪念玻璃，独立站/Etsy 成交 |
| 价值链 5–7 环 | 每环谁做、成本、风险 | 设计→工厂→质检→拍摄→上架→客服→物流→售后 |
| 你掌控的环节 | 哪些自己做、哪些外包 | 设计/内容/客服自己做；生产外包；物流用海外仓 |
| 交付方式与周期 | 实物/数字/服务；交期 | 定制 2–3 周；直邮 7–15 天 |
| 关键合作方 | 工厂/物流/支付/审校 | 玻璃厂、跨境物流、支付服务商、宗教学者 |

**信息从哪查**：
- 同类公司的「关于我们/供应链」页面、招聘岗位（看他们自建什么环节）；
- 平台入驻要求与履约规则；
- 工厂/物流/支付服务商报价；
- 行业报告的价值链图（注意甄别营销稿）；
- 自己画一遍流程，标出每一步的成本与时间。

**判断标准**：

| 等级 | 标准 |
|---|---|
| 不合格 | 只写「开个店/做个品牌」；没有价值链、没有交付方式 |
| 合格 | 写清模式 + 3–5 个价值链环节 + 交付方式 |
| 优秀 | 画出完整链条、标出掌控/外包环节、给出交付周期与成本、识别单点故障 |

**常见错误**：

| 错误 | 为什么错 | 怎么改 |
|---|---|---|
| 模式与收入不匹配 | 说做订阅却靠一次性卖货 | 模式、收入、交付三者对齐 |
| 低估履约复杂度 | 定制/跨境/退换货吃掉利润 | 把履约画进价值链，算时间与成本 |
| 什么都自己做 | 个人产能有限 | 只掌控核心环节（设计/内容/客户关系），其余外包 |
| 单点依赖 | 一个工厂/一个平台/一个物流商 | 每个环节至少备 1 个替代 |
| 忽略合规环节 | 认证/税务/宗教审校 | 把合规作为价值链的一环 |

**追问清单**：
1. 客户付钱后，从下单到收货经过哪几步？每步谁做、多久、多少钱？
2. 哪一步最容易出问题？有没有备选？
3. 哪一步是你的核心能力？哪一步可以外包？
4. 这个模式能复制到第二个国家/平台吗？

**示范答案 A（宠物纪念玻璃）**：

> 模式：DTC 定制 + Etsy/独立站成交 + 国内玻璃工艺厂代工 + 海外仓/直邮。价值链：①原创设计/款式（自己做）→ ②玻璃工艺生产（1688 工厂，$25–60/件）→ ③质检与防碎包装（自己做/工厂代做）→ ④拍摄与 listing（自己做）→ ⑤Etsy/独立站成交（平台+自己客服）→ ⑥跨境物流（直邮 7–15 天或海外仓 3–5 天）→ ⑦售后/退换（自己）。核心掌控：设计、内容、客户关系、质检标准；外包：生产、物流。单点故障：玻璃良率与破损率——需 2 家备选工厂 + 防碎包装测试。

**示范答案 B（中东宗教内容本地化）**：

> 模式：B2B 本地化服务 + 审校 + 数字产品（`service` + `infoproduct`）。价值链：①内容获取（出版社/学校提供英文/中文原稿）→ ②翻译（自己/兼职译员）→ ③宗教审校（签约宗教学者，按项目付费）→ ④排版/本地化设计（外包本地设计师）→ ⑤交付（PDF/印刷文件/LMS 上传）→ ⑥维护更新（教材改版时二次收费）。核心掌控：审校网络、客户信任、项目管理；外包：翻译（可扩产能）、设计、印刷。单点故障：审校学者——必须签 2–3 位备选，且明确审校责任边界。

### 1.4 第四问：投入回报与时间周期

**要回答的四个子问题**：
1. **启动资金**：最少要花多少？花在哪几项？
2. **时间**：多久出第一笔收入？多久回本？
3. **回报**：月收入区间、毛利率、净利、收入天花板？
4. **现金流**：先收后付还是先付后收？有没有账期/库存占款？最坏情况亏多少？

**必答结构**：

| 要素 | 必须写清 | 示例 |
|---|---|---|
| 启动资金分项 | 样品/库存/拍摄/网站/认证/广告/备用金 | 样品 1500 + 拍摄 1500 + 首批库存 8000 + 广告 1000 |
| 首收入时间 | 从启动到第一笔收入 | 2–3 个月 |
| 回本周期 | 累计净利 ≥ 启动资金所需月数 | 5–6 个月 |
| 月收入区间 | 保守/基准/乐观三档 | 8k–30k 元 |
| 毛利率 / 净利率 | 毛利扣完成本后的净利 | 毛利 65%，净利 25–35% |
| 现金流特征 | 先收后付/垫资/账期 | 客户先付、工厂 30% 定金、库存占款 1–2 万 |
| 最大损失 | 最坏情况亏多少、能否承受 | ≤2 万元，可承受 |
| 止损线 | 什么条件下停 | 3 个月无自然询盘 / 连续 2 个月净亏 |

**信息从哪查**：
- 供应商报价（1688/Alibaba/本地工厂）；
- 平台费用表（佣金、支付、广告、仓储）；
- 物流/关税/退货率（问货代、看平台政策）；
- 同类卖家访谈/公开复盘（注意幸存者偏差）；
- 自己的时间成本（按当地时薪折算）；
- 汇率与税费（跨境必须算）。

**判断标准**：

| 等级 | 标准 |
|---|---|
| 不合格 | 只写「成本低、利润高」；无资金、无回本、无毛利 |
| 合格 | 给启动资金、首收入时间、回本周期、月收入区间、毛利 |
| 优秀 | 给三档情景、现金流特征、最大损失、止损线、盈亏平衡点 |

**常见错误**：

| 错误 | 为什么错 | 怎么改 |
|---|---|---|
| 只算硬成本 | 时间、生活成本、机会成本没算 | 把时间按市价折算，至少列 10% 备用金 |
| 回本周期乐观 | 忽略冷启动、退货、账期 | 用「保守情景」做决策，乐观情景只做参考 |
| 忽略现金流 | 有利润但没钱周转 | 画现金流表：什么时候收、什么时候付 |
| 没有止损线 | 越亏越投 | 写清 3 条止损条件 |
| 把一次性收入当月收入 | 首月爆单不代表可持续 | 用 3–6 个月平均，区分季节性 |

**追问清单**：
1. 启动资金里，哪一项最可能超支？超多少？
2. 第一笔收入之前，你要垫多少钱、垫多久？
3. 最坏情况下亏多少？这个数字你晚上睡得着吗？
4. 如果 3 个月没起色，你停不停？停的条件是什么？

**示范答案 A（宠物纪念玻璃）**：

> 启动资金 3000–8000 元：样品与打样 1500、拍摄与设计 1500、首批库存/包装 3000–5000、Etsy/独立站与广告测试 1000。首收入 2–3 个月；回本 5–6 个月（月净利 2000–5000）。月收入 8000–30000 元（约 8–20 单），毛利 65%，净利 25–35%。现金流：客户先付款，工厂 30% 定金、尾款发货前付，库存占款 1–2 万元，无长账期。最大损失 ≤2 万元（可承受）；止损线：3 个月无自然询盘、样品良率 <80%、头部价格打到 $60 以下。

**示范答案 B（中东宗教内容本地化）**：

> 启动资金 5000–15000 元：样章翻译+审校 3000–6000、案例页/网站 1000–2000、展会/差旅 2000–5000、合同/法务 500–1000、备用金 2000。首收入 3–4 个月（B2B 销售周期长）；回本 6–9 个月。月收入 1–5 万元（2–5 个 B2B 客户 + C 端数字产品），毛利 60–75%，净利 30–40%。现金流：B2B 预付 30–50%，账期 30–90 天，需垫付审校专家费；C 端即时收款可补现金流。最大损失 ≤1.5 万元；止损线：6 个月签不下 1 个付费客户、找不到 2 位可签约审校、涉及教派争议无法取得书面授权。

### 1.5 第五问：适合人群（谁不适合）

**要回答的三个子问题**：
1. **最适合谁**：什么资源、技能、语言、身份、时间结构的人做最顺？
2. **不适合谁**：什么人做了大概率失败？为什么？
3. **替代方案**：如果我不适合，谁能做？我能不能只做其中一环？

**必答结构**：

| 要素 | 必须写清 | 示例 |
|---|---|---|
| 最适合画像（2–3 类） | 资源/技能/语言/身份/时间 | 有审美+英语可读+能接受定制的兼职者 |
| 明确不适合 | 3 类人 + 原因 | 想纯铺货、怕售后、无审美者 |
| 硬门槛 | 资质/语言/身份/资金 | 需动物遗骸合规知识；英语读写 |
| 软门槛 | 可学习的能力 | 拍摄、客服、基础 SEO |
| 失败退出路径 | 做不下去时怎么退 | 库存清仓、listing 转让、转做内容 |

**信息从哪查**：
- 同类从业者的背景访谈（他们之前做什么）；
- 招聘岗位要求（说明能力门槛）；
- 目标市场的身份/语言要求（本地身份、宗教背景、行业资质）；
- 自己的真实时间表（不是理想时间表）；
- 家庭/主业约束（能否兼职、能否出差）。

**判断标准**：

| 等级 | 标准 |
|---|---|
| 不合格 | 写「适合所有人」「适合小白」「只要努力就能做」 |
| 合格 | 写清 2–3 类最适合的人 + 明确不适合的人 |
| 优秀 | 写清硬/软门槛、替代执行者、失败退出路径、需要补齐的能力与时间 |

**常见错误**：

| 错误 | 为什么错 | 怎么改 |
|---|---|---|
| 「适合所有人」 | 没有门槛=没有优势，也误导他人 | 写出至少 3 类不适合的人 |
| 把兴趣当能力 | 喜欢宠物 ≠ 会做宠物生意 | 用「是否做过/是否有资源」判断 |
| 忽略语言/身份 | 跨境/宗教/本地服务有硬门槛 | 把语言/身份写成硬条件 |
| 忽略时间结构 | 兼职做需要 2 倍周期 | 用真实可用时间算产能 |
| 不写退出路径 | 失败后损失更大 | 设计清库存/转内容/转服务的退路 |

**追问清单**：
1. 这件事需要什么硬门槛？我有吗？没有的话 30 天能补吗？
2. 谁做这件事比我更有优势？我能不能和他合作？
3. 我每周真实可投入多少小时？能持续多久？
4. 如果做失败，我能收回多少？怎么退？

**示范答案 A（宠物纪念玻璃）**：

> 最适合：①有审美、会拍照、英语可读写的兼职者（设计师/电商运营/宠物行业从业者）；②有跨境经验、能对接工厂与物流的人；③宠物殡葬/宠物内容从业者（自带信任）。不适合：想纯铺货不碰定制的、怕售后与退货的、没有审美与内容能力的、无法接受 2–3 周交期的。硬门槛：英语读写（客服/listing）、动物遗骸/骨灰跨境合规知识；软门槛：拍摄、SEO、客服（可学）。退出路径：库存清仓、Etsy listing 转让、转做宠物纪念内容/测评。

**示范答案 B（中东宗教内容本地化）**：

> 最适合：①有阿拉伯语能力或中东生活/工作背景的人；②有出版/教育行业经验、懂教材本地化流程的人；③有宗教学者/教育机构资源的人。不适合：无阿语能力且无本地伙伴的、无宗教知识又不愿请审校的、想赚快钱的、对合规与教派敏感无耐心的。硬门槛：阿语（或可靠阿语合伙人）、宗教学者审校资源、出版授权知识；软门槛：项目管理、B2B 销售（可学）。退出路径：转做通用阿语本地化、转做教育内容分销、以顾问身份与本地公司合作。

### 1.6 第六问：驱动类型（为什么现在成立）

**要回答的三个子问题**：
1. **主驱动**：这个机会主要靠什么力量推动？（7 选 1–3）
2. **强度与持续性**：这个力量有多强？还能持续多久？
3. **为什么是现在**：如果没有这个驱动，机会还成立吗？

**7 个驱动（docs/12 §3.6，原样引用）**：

| id | 名称 | 核心含义 | 识别信号 | 典型机会 | 个人可做性 | 风险 |
|---|---|---|---|---|---|---|
| `capital` | 资本驱动 | 有钱涌入（融资/补贴/消费升级） | 融资新闻、补贴政策、消费升级数据 | 新消费品牌、平台补贴套利 | 中 | 补贴退坡、资本寒冬 |
| `tech` | 技术驱动 | 新技术成熟/成本下降 | 模型/硬件/API 降价、开源项目 | AI 工具、自动化、SaaS | 中高 | 技术迭代、巨头碾压 |
| `info` | 传播信息驱动 | 信息从 A 传到 B 但未传开 | 内容平台热度、跨语言搬运、社群讨论 | 内容出海、知识产品、选品 | 高 | 信息差快速消失 |
| `cross-border` | 跨国驱动 | 需求在 A 国、供给在 B 国/价差 | 价差、代购、集运、平台跨国扩张 | 跨境 DTC、贸易、代运营 | 中高 | 关税/汇率/合规 |
| `regulation` | 政策驱动 | 新法规/认证/关税/补贴创造刚需 | 法规生效、平台下架潮、招标 | 合规服务、认证、政策内容 | 中 | 政策变化、责任风险 |
| `ops` | 运营驱动 | 效率/履约/服务体验有巨大改进空间 | 差评里的服务问题、履约慢、信息不透明 | 代运营、SaaS、服务标准化 | 高 | 人力密集、难放大 |
| `supply` | 供应链驱动 | 供应链层级/成本/柔性优势 | 工厂直供、产业带、柔性定制 | 跨境分销、白牌、定制 | 中高 | 库存、价格战 |

**必答结构**：

| 要素 | 必须写清 | 示例 |
|---|---|---|
| 主驱动（1 个） | 从 7 个 id 选 1 个 | `info` |
| 辅助驱动（0–2 个） | 与主驱动互补 | `cross-border` |
| 驱动强度 | 强/中/弱 + 证据 | 强：跨语言内容差 ≥12 个月 |
| 持续性 | 还能持续多久 | 12–24 个月 |
| 为什么现在 | 触发事件 | 平台开放新站点、AI 翻译成本下降 |
| 反事实 | 没有这个驱动机会还成立吗 | 不成立 → 驱动判断正确 |

**判断标准**：

| 等级 | 标准 |
|---|---|
| 不合格 | 写「因为市场大」「因为趋势」；驱动 id 与机会不匹配 |
| 合格 | 从 7 个 id 选 1–3 个，并解释为什么 |
| 优秀 | 说明驱动强度/持续性/触发事件，并用反事实检验 |

**常见错误**：
- 把「趋势」当驱动（趋势是现象，驱动是力量）；
- 选 4 个以上驱动（等于没选）；
- 驱动与 `gap_type` 不匹配（如平台规则差却写资本驱动）；
- 只有驱动没有触发事件（不知道现在为什么是现在）。

**追问清单**：
1. 如果没有这个驱动，这个机会还成立吗？
2. 这个驱动还能持续多久？什么事件会让它消失？
3. 驱动是「一次性」还是「结构性」？
4. 这个驱动为什么轮到我（而不是巨头）？

**示范答案 A（宠物纪念玻璃）**：

> 主驱动 `info`（宠物纪念/哀悼消费在欧美已被验证，跨语言/跨平台信息差仍在，中国供应链与海外需求之间的信息不对称）；辅助 `cross-border`（中国玻璃工艺成本优势 + 跨境物流成熟）。强度中强，持续性 12–24 个月；触发事件：宠物人性化消费升级 + Etsy/Pinterest 内容传播 + 跨境物流成本下降。反事实：如果没有跨语言/跨境信息差，这个品类在欧美本地已有手工供给，机会会明显缩小——说明 `info` 判断成立。

**示范答案 B（中东宗教内容本地化）**：

> 主驱动 `info`（中文/英文教育内容与阿拉伯语市场之间的信息差 + 宗教专业知识差）；辅助 `regulation`（教材审批、宗教内容规范、出版授权）与 `cross-border`（中国/英文出版社与海湾市场的连接）。强度强（宗教/语言门槛高、供给稀缺），持续性强（文化差半衰期 36 个月）；触发事件：海湾国家教育数字化 + 家庭学校增长 + 中阿教育合作增加。反事实：如果去掉宗教审校门槛，普通翻译公司就能做，机会消失——说明门槛即驱动。

### 1.7 第七问：壁垒与前置条件

**要回答的三个子问题**：
1. **壁垒**：我能建立什么壁垒？如果没有，诚实说「窗口期套利」。
2. **前置条件**：做这件事之前必须具备什么（资质/供应链/资金/人脉/知识）？
3. **防御**：别人复制我需要多久？我怎么应对？

**壁垒类型速查（详见 §4）**：品牌 / 供应链 / 数据 / 网络效应 / 合规牌照 / 工艺 / 渠道 / 内容 IP / 规模 / 切换成本 / 成本优势 / 本地关系 / 速度 / 社区。

**必答结构**：

| 要素 | 必须写清 | 示例 |
|---|---|---|
| 壁垒类型（1–2 个） | 从清单选 + 解释 | 工艺 + 内容 IP |
| 建立路径 | 怎么从 0 到 1 | 3 个月打样 20 款、积累 100 条真实好评 |
| 前置条件 | 必须有的资源/资质 | 稳定玻璃供应商、防碎包装方案、合规知识 |
| 复制难度 | 别人复制要多久/多少钱 | 6–12 个月 + 5 万元 |
| 防御动作 | 怎么拉开差距 | 专利外观、独家工艺、KOL 绑定 |
| 诚实声明 | 没有壁垒就直说 | 「窗口期套利，无长期壁垒」 |

**判断标准**：

| 等级 | 标准 |
|---|---|
| 不合格 | 只写「没有壁垒」「靠努力」「先发优势」 |
| 合格 | 说出 1 种壁垒或诚实说「窗口期套利」+ 前置条件 |
| 优秀 | 壁垒类型 + 建立路径 + 前置条件 + 复制难度 + 防御动作 |

**常见错误**：
- 把「先发」当壁垒（先发只给你 3–6 个月）；
- 把「努力/服务好」当壁垒（可被复制）；
- 忽略合规壁垒（牌照/认证是最硬的壁垒之一）；
- 过度承诺壁垒，导致自己误判竞争；
- 不写前置条件（做的时候才发现缺资质）。

**追问清单**：
1. 如果明天出现 10 个模仿者，我还剩什么？
2. 我的壁垒需要多久建立？需要多少钱/资源？
3. 有没有「必须有但不能马上有」的前置条件？
4. 如果没有任何壁垒，我准备赚多久的窗口钱？

**示范答案 A（宠物纪念玻璃）**：

> 壁垒：工艺（玻璃良率与防碎包装）+ 内容 IP（原创设计、真实客户故事、Pinterest/TikTok 内容资产）。建立路径：3 个月打样 20 款、筛出 5 款爆款；积累 100 条真实好评与 UGC；申请外观专利（可选）。前置条件：稳定玻璃供应商（≥2 家）、防碎包装测试通过、目的国动物遗骸合规确认。复制难度：6–12 个月 + 3–5 万元。防御：独家款式 + 快速上新 + 与宠物殡葬博主长期绑定。诚实声明：如果只做「1688 同款搬运」，就是窗口期套利，无长期壁垒。

**示范答案 B（中东宗教内容本地化）**：

> 壁垒：合规牌照/资质（宗教学者审校网络 + 出版授权）+ 本地关系（出版商/学校信任）+ 内容 IP（审校过的教材库）。建立路径：签约 2–3 位可背书的审校学者；完成 3 个标杆项目并取得推荐；积累可复用的术语库与审校 SOP。前置条件：阿语能力/合伙人、宗教知识、出版授权与合同模板、数据/内容保密协议。复制难度：12–24 个月（学者资源与信任难复制）。防御：与学者签排他/优先合作、做深垂直品类（儿童伊斯兰教育）、建立术语库壁垒。诚实声明：如果只是「普通翻译+机翻润色」，没有壁垒，且宗教风险高。

## 2. 驱动类型判定树

### 2.1 判定树（从上到下，命中即停）

```
这个机会为什么现在成立？
│
├─ ① 有新钱进入（融资/补贴/消费升级/政策资金）？
│     └─ 是 → capital（资本驱动）
│
├─ ② 有新技术成熟/成本骤降/新工具出现？
│     └─ 是 → tech（技术驱动）
│
├─ ③ 信息/内容/玩法从 A 地传到 B 地，但还没传开？
│     └─ 是 → info（传播信息驱动）
│
├─ ④ 需求在 A 国、供给在 B 国，或存在明显价差/套利？
│     └─ 是 → cross-border（跨国驱动）
│
├─ ⑤ 新法规/认证/关税/补贴/招标创造了「必须做」的需求？
│     └─ 是 → regulation（政策驱动）
│
├─ ⑥ 现有履约/服务/效率有巨大改进空间（差评多、流程烂）？
│     └─ 是 → ops（运营驱动）
│
└─ ⑦ 供应链层级/成本/柔性/产业带优势明显？
      └─ 是 → supply（供应链驱动）
```

**判定纪律**：
- 先问「如果没有这个力量，机会还成立吗？」不成立才是真驱动；
- 主驱动只能 1 个，辅助最多 2 个；
- 驱动必须与 `gap_type` 自洽（例：`platform` 规则差 → 通常是 `regulation` 或 `info`，不是 `capital`）；
- 驱动持续时间写进 `window` 判断（docs/04 §4）。

### 2.2 七类驱动深表

| 驱动 | 机会成立的必要条件 | 强度信号 | 持续性 | 个人可做性 | 最大风险 | 典型 gap_type 组合 |
|---|---|---|---|---|---|---|
| `capital` | 有钱持续流入，且流入方需要服务/供给 | 融资额、补贴额度、消费增速 | 1–3 年（周期性强） | 中 | 补贴退坡、资本寒冬 | `time` + `price` |
| `tech` | 技术成本下降或能力跃迁，且存在应用空档 | API 价格、开源生态、硬件成本 | 1–2 年（迭代快） | 中高 | 巨头碾压、技术过时 | `knowledge` + `platform` |
| `info` | 信息/内容/玩法存在跨语言/跨平台/跨圈层差 | 内容热度、搜索差、社群讨论 | 6–24 个月 | 高 | 信息差快速消失 | `language` + `channel` |
| `cross-border` | 跨国价差/供需差 > 成本（物流+关税+合规） | 价差、代购、集运、平台扩张 | 1–3 年 | 中高 | 关税/汇率/合规 | `geo` + `price` |
| `regulation` | 新规强制执行，且企业必须合规 | 法规生效日、下架潮、招标 | 2–5 年 | 中 | 政策变化、责任风险 | `regulation` + `language` |
| `ops` | 现有服务体验差、效率低、信息不透明 | 差评、等待时间、投诉率 | 2–5 年 | 高 | 人力密集、难放大 | `channel` + `emotion` |
| `supply` | 供应链成本/柔性/产业带优势可转化为产品优势 | 工厂直供、起订量、交期 | 1–3 年 | 中高 | 库存、价格战 | `price` + `geo` |

### 2.3 判定演练

**演练 1：宠物纪念玻璃**
- 有新钱进入？宠物消费升级是慢变量，不是「新钱」→ 否；
- 新技术？玻璃工艺是成熟工艺 → 否；
- 信息差？欧美已有人做，但中国供应链与跨境信息差仍在 → 是 → `info`；
- 跨国？中国供应链 → 欧美需求 → 是 → `cross-border`；
- 结论：`info` + `cross-border`（与 docs/12 示例一致）。

**演练 2：中东宗教教育内容本地化**
- 有新钱？教育数字化有投入，但不是主因 → 弱；
- 新技术？AI 翻译降低成本，但宗教内容不能靠 AI → 辅助；
- 信息差？中文/英文内容与阿语市场的信息差 + 宗教知识差 → 是 → `info`；
- 政策？教材审批/宗教规范/出版授权 → 是 → `regulation`；
- 跨国？跨市场交付 → 是 → `cross-border`；
- 结论：`info` + `regulation` + `cross-border`。

### 2.4 驱动组合规律

| 组合 | 效果 | 例子 | 注意 |
|---|---|---|---|
| `info` + `cross-border` | 信息差 + 地理差，最经典的跨境套利 | 中国供应链 → 欧美内容电商 | 窗口短，需快速建品牌 |
| `regulation` + `info` | 政策刚需 + 信息不对称，壁垒高 | EPR/CE/清真认证代办 | 责任风险高，需专业背书 |
| `tech` + `info` | 新工具 + 认知差，适合个人 | AI 工具本地化、自动化服务 | 技术迭代快 |
| `supply` + `cross-border` | 供应链 + 跨国，规模潜力大 | 产业带白牌出海 | 库存与价格战 |
| `ops` + `info` | 服务差 + 信息差，适合服务型个人 | 代运营、跨境客服 | 人力密集 |
| `capital` + `supply` | 资本 + 供应链，适合团队 | 新消费品牌 | 个人难参与 |

### 2.5 常见误判

| 误判 | 表现 | 纠正 |
|---|---|---|
| 把「趋势」当驱动 | 「宠物经济增长」当驱动 | 趋势是背景，驱动是「为什么现在」 |
| 驱动选太多 | 7 个里选 5 个 | 最多 3 个，主驱动 1 个 |
| 驱动与 gap 不匹配 | `platform` 差却写 `capital` | 用 §2.1 判定树重走 |
| 忽略驱动消失条件 | 不写「什么会让驱动消失」 | 写进 `kill_criteria` |
| 把「政策红利」当长期 | 补贴期一过就死 | 设计补贴退坡后的商业模式 |

## 3. 商业模式形态与价值链

### 3.1 12 种商业模式（docs/12 §3.7，原样引用）

| id | 名称 | 价值链核心 | 收入结构 | 适合人群 | 案例方向 | 主要坑 |
|---|---|---|---|---|---|---|
| `dtc` | DTC 品牌 | 设计→生产→品牌→独立站/平台→用户 | 产品销售 + 加购 | 有审美/内容/供应链 | 宠物纪念玻璃、家居品牌 | 获客成本、库存 |
| `marketplace` | 平台/撮合 | 供给端→平台→需求端 | 佣金/广告/会员 | 有双边资源/技术 | 垂直服务撮合、二手 | 冷启动双边、信任 |
| `service` | 服务交付 | 需求→方案→交付→售后 | 项目费/时薪 | 有专业技能 | 合规咨询、代运营 | 依赖个人时间 |
| `subscription` | 订阅制 | 内容/产品→持续交付→留存 | 月费/年费 | 能持续产出 | 宠物盒、SaaS、会员 | 留存与流失率 |
| `infoproduct` | 信息产品 | 知识→课程/报告/社群 | 一次性购买/会员 | 有专业知识/表达 | 小语种课程、行业报告 | 同质化、退款 |
| `saas` | 工具/SaaS | 需求→产品→订阅→留存 | 月费/年费 | 有技术/产品 | 垂直行业工具 | 获客、巨头 |
| `agency` | 代运营/代理 | 客户→策略→执行→报表 | 月费/佣金 | 有运营经验 | 跨境代运营、广告投放 | 人力密集、客户流失 |
| `licensing` | 授权/IP | IP→授权→分成 | 授权费/分成 | 有 IP/内容 | 形象授权、翻译授权 | 版权谈判 |
| `affiliate` | 联盟/分成 | 内容→流量→联盟链接 | 佣金 | 有流量/内容 | 测评号、导购 | 平台政策、信任 |
| `arbitrage` | 套利/贸易 | 低价市场→高价市场 | 价差 | 有供应链/渠道 | 跨境贸易、尾货 | 关税/汇率/库存 |
| `community` | 社群会员 | 内容→社群→会员 | 会员费/活动 | 有社群运营能力 | 行业社群、兴趣社群 | 活跃度、续费 |
| `consulting` | 咨询顾问 | 诊断→方案→陪跑 | 项目费/顾问费 | 有行业经验/背书 | 合规、出海、战略 | 依赖个人品牌 |

**组合规则**：真实机会常是「主模式 + 辅模式」：
- 实物：`dtc` + `affiliate`（内容带货）+ `subscription`（补充装）；
- 服务：`service` + `consulting` + `infoproduct`（把服务产品化）；
- 信息：`infoproduct` + `community` + `affiliate`；
- 技术：`saas` + `service`（实施/定制）。

### 3.2 价值链画法（5 步）

1. **列出从原料/内容到客户的全部环节**（5–9 个）；
2. **标注每个环节**：谁做、耗时、成本、风险、是否需要资质；
3. **标出你掌控的环节**（核心能力）与**外包环节**；
4. **找单点故障**：哪个环节断掉，生意就停？备选是什么？
5. **算总交付成本与周期**：从客户付钱到收货/交付完成。

**示例（宠物纪念玻璃）**：

| 环节 | 谁做 | 耗时 | 成本 | 风险 | 是否掌控 |
|---|---|---|---|---|---|
| 款式设计 | 自己 | 1–2 天/款 | 时间 | 同质化 | ✅ |
| 玻璃生产 | 1688 工厂 | 5–10 天 | $25–60/件 | 良率、交期 | ❌（需备选） |
| 质检/防碎包装 | 自己/工厂 | 0.5 天 | $8–15 | 破损 | ✅ |
| 拍摄/listing | 自己 | 1 天/10 款 | $100–300 | 点击率 | ✅ |
| 成交/客服 | Etsy/独立站 + 自己 | 即时 | 佣金 6.5% | 差评 | ✅ |
| 跨境物流 | 直邮/海外仓 | 7–15 天 | $20–40 | 丢件/时效 | ❌ |
| 售后/退换 | 自己 | 不确定 | 5% 计提 | 破损退款 | ✅ |

### 3.3 收入结构组合（写进第二问）

| 收入类型 | 典型占比 | 优点 | 缺点 | 适合阶段 |
|---|---|---|---|---|
| 实物销售 | 60–90% | 直观、可验证 | 库存、物流 | 启动期 |
| 服务费 | 40–80% | 轻资产、高毛利 | 依赖个人时间 | 启动期/专业型 |
| 信息产品 | 10–40% | 边际成本低 | 同质化、退款 | 有受众后 |
| 订阅 | 20–60% | 现金流稳定 | 留存压力 | 有产品后 |
| 佣金/分成 | 5–30% | 无库存 | 平台政策、信任 | 有流量后 |
| 广告 | 5–20% | 流量变现 | 伤体验、依赖平台 | 有流量后 |

**健康结构原则**：主收入 ≥50%，第二收入 15–35%，其余 ≤15%；单一收入 >90% 视为高风险（写进 `risks`）。

### 3.4 模式选择决策树

```
你手里最硬的资源是什么？
├─ 供应链/工厂 → dtc / arbitrage / supply 驱动
├─ 专业技能 → service / consulting / agency
├─ 内容/流量 → affiliate / infoproduct / community
├─ 技术 → saas / tech 驱动
├─ 双边资源 → marketplace
├─ IP/版权 → licensing
└─ 什么都没有，只有时间 → 先做 service/affiliate 积累，再转产品
```

**选择纪律**：
- 资源决定模式，不是「想做什么模式」；
- 启动期选「现金流快、验证快」的模式（service/arbitrage/dtc 小批量）；
- 放大期再转「可复制」的模式（subscription/saas/infoproduct）；
- 不要一开始就做 marketplace/SaaS（双边/技术门槛高）。

## 4. 壁垒类型清单与前置条件

### 4.1 14 种壁垒

| # | 壁垒类型 | 定义 | 如何建立 | 前置条件 | 验证方法 | 个人可行性 |
|---|---|---|---|---|---|---|
| 1 | 品牌 | 用户认牌子、愿意溢价 | 持续内容+真实口碑+时间 | 稳定品质、内容能力 | 复购率、搜索品牌词 | 中（慢） |
| 2 | 供应链 | 独家货源/成本/交期优势 | 工厂关系、独家协议、规模采购 | 起订量、资金、验厂 | 报价对比、交期 | 中 |
| 3 | 数据 | 独有数据/算法/用户行为 | 长期积累、闭环反馈 | 用户量、合规 | 数据量、模型效果 | 低-中 |
| 4 | 网络效应 | 用户越多价值越大 | 双边/社群/平台 | 冷启动、密度 | 留存、活跃、匹配效率 | 低 |
| 5 | 合规牌照 | 牌照/认证/资质门槛 | 申请、合作、并购 | 资金、时间、资质 | 牌照/证书 | 低-中 |
| 6 | 工艺 | 独有技术/手艺/良率 | 研发、师徒、设备 | 时间、设备、经验 | 良率、成本、专利 | 中 |
| 7 | 渠道 | 独家渠道/分销/线下网络 | 签约、返点、服务 | 关系、资金、履约 | 渠道覆盖、动销 | 中 |
| 8 | 内容 IP | 版权/形象/课程/社群内容 | 原创、签约、授权 | 创作能力、版权 | 版权登记、粉丝 | 中-高 |
| 9 | 规模 | 规模带来的成本/议价优势 | 增长、融资、并购 | 资金、市场 | 单位成本曲线 | 低 |
| 10 | 切换成本 | 用户迁移成本高 | 数据沉淀、集成、习惯 | 产品深度 | 流失率、迁移调研 | 中 |
| 11 | 成本优势 | 结构性低成本 | 供应链、自动化、地理 | 规模/技术 | 成本对比 | 中 |
| 12 | 本地关系 | 本地政府/社群/宗教/家族关系 | 长期经营、合作、背书 | 身份、时间、信任 | 合作方数量、转介绍 | 中-高（需本地） |
| 13 | 速度 | 比对手快 3–6 个月 | 快速迭代、小步验证 | 执行速度、决策链短 | 上新速度、窗口占位 | 高 |
| 14 | 社区 | 用户归属感/共创/身份 | 运营、活动、价值观 | 内容/运营能力 | 活跃、留存、UGC | 中-高 |

**壁垒强度评分（0–3 分/项，加总 0–42）**：

| 分数 | 含义 | 行动 |
|---|---|---|
| 25–42 | 强壁垒 | 可重注，长期投入 |
| 15–24 | 中等壁垒 | 可做，但需持续加固 |
| 8–14 | 弱壁垒 | 只能赚窗口钱，设退出条件 |
| 0–7 | 无壁垒 | 诚实写「窗口期套利」，快进快出 |

### 4.2 无壁垒的诚实写法

**允许**（不丢人）：
> 「本机会为窗口期套利：依赖 `platform` 规则差（半衰期 6 个月），无长期壁垒。策略是 3 个月内快速验证、6 个月内收回投入，窗口关闭即退出。前置条件：平台账号合规、供应链稳定。」

**不允许**：
> 「壁垒是努力/服务好/先发优势/我比别人聪明。」——这些不是壁垒，是可被复制的态度。

### 4.3 壁垒与竞争维度匹配

| 竞争维度 | 对应壁垒 | 如果对手打价格战 | 如果对手打品牌 | 如果巨头进场 |
|---|---|---|---|---|
| 价格 | 成本优势/规模 | 只能跟或退出 | 做差异化 | 转细分/服务 |

### 6.3 一页纸尽调清单（35 项）

**A. 需求与信号（7 项）**
- [ ] 至少有 3 条独立一手信号，跨 ≥2 平台，时间跨度 ≥30 天；
- [ ] 有行为证据（付费/复购/DIY/退货/搜索），不只是情绪表达；
- [ ] 目标市场本地语言有一手信号（非纯英文转述）；
- [ ] 能给出规模量级（销量/搜索量/评论数/招标额）；
- [ ] 主动搜索过失败/退出/投诉，未发现致命反证或已解释；
- [ ] 信号能追溯到具体 URL/截图，日期在 12 个月内；
- [ ] 能一句话说清「谁、在什么场景、为什么现在要」。

**B. 需求归因（3 项）**
- [ ] 命中 12 个底层需求中的 1–3 个，有原声支撑；
- [ ] 需求强度是「痛」或「流血」，不是「痒」；
- [ ] 能说清触发事件（何时需求最强）。

**C. 场景与缺口（5 项）**
- [ ] 场景具体到「某天某个时刻」，不是人群标签；
- [ ] 能画出用户现有解决路径（≥3 步、≥3 个摩擦点）；
- [ ] 现有供给在 ≥2 个维度不满足；
- [ ] 用户正在为替代方案付出可量化代价；
- [ ] 缺口有「为什么现在」的解释。

**D. 流量与变现（6 项）**
- [ ] 写清 1–2 个主渠道 + 内容形式 + 搜索词；
- [ ] 前 100 个客户的具体来源与动作；
- [ ] 收入类型 + 客单 + 毛利 + 收入占比；
- [ ] 有复购/加购/订阅设计（或说明为何不需要）；
- [ ] CAC 上限与测试预算；
- [ ] 至少 2 种收入类型（或说明单类型合理性）。

**E. 模式与回报（6 项）**
- [ ] 模式 id + 一句话模式 + 价值链 5–7 环；
- [ ] 标出自己掌控/外包的环节与单点故障；
- [ ] 启动资金分项 + 首收入时间 + 回本周期；
- [ ] 三档情景（保守/基准/乐观）；
- [ ] 现金流特征（先收后付/账期/库存占款）；
- [ ] 最大损失与止损线。

**F. 人与驱动（5 项）**
- [ ] 最适合 2–3 类人 + 明确不适合 3 类人；
- [ ] 硬门槛（语言/资质/身份/资金）已确认；
- [ ] 执行者能力向量与机会需求匹配（docs/04 §5）；
- [ ] 主驱动 1 个 + 辅助 ≤2 个，有反事实检验；
- [ ] 驱动持续时间与消失条件（写进 kill_criteria）。

**G. 壁垒、风险与合规（3 项）**
- [ ] 壁垒类型 + 建立路径 + 复制难度（或诚实写套利）；
- [ ] 风险 2–5 条，具体到触发条件，有缓释方案；
- [ ] 合规说明（资质/宗教/版权/平台/数据），黑榜已排除。

### 6.4 七问自检红线（答不上来说明什么）

| 壁垒与前置条件 | 壁垒：宗教审校网络（合规/资质）+ 本地关系（出版商信任）+ 内容 IP（审校教材库）；建立路径：签约 2–3 位可背书学者、完成 3 个标杆项目、积累术语库/审校 SOP；前置：阿语能力、出版授权、保密协议；复制难度 12–24 个月；普通机翻无壁垒且风险高。 |

## 8. 评审流程与版本

### 8.1 七问评审 5 步

1. **完整性**：7 个字段齐全、非空、无占位词（V04）；
2. **一致性**：七问与顶层 `roi`、`drivers`、`scores` 一致（数值/枚举）；
3. **可执行性**：第一、二、四问是否具体到 7 天能动手；
4. **可证伪性**：`kill_criteria` 是否具体、可观测、有触发阈值；
5. **合规性**：是否命中黑榜/黄榜；宗教/医疗/金融/版权是否已标注。

### 8.2 常见退回原因

| 退回原因 | 例子 | 修复 |
|---|---|---|
| 空洞 | 「流量靠平台，赚钱靠卖货」 | 补具体平台/词/客单/成本 |
| 不一致 | 七问说订阅，roi 是一次性 | 统一模式与收入 |
| 不可验证 | 「先做品牌，再看市场」 | 改成 7 天可验证动作 |
| 乐观 | 回本 1 个月无依据 | 保守情景 + 50% 缓冲 |
| 无壁垒 | 「靠努力」 | 诚实写套利 + 退出条件 |
| 合规缺失 | 宗教/医疗内容无审校 | 加审校/资质/免责 |
| 人群错配 | 「适合所有人」 | 写不适合的 3 类人 |
