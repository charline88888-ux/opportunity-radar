## 1. 执行摘要（300 字版）

全世界每天都在产生"有人愿意付钱、但供给还没跟上"的信息差。它们散落在 Reddit 的抱怨、Etsy 的评论区、沙特的主妇群、日本的二手平台、欧盟的法规公报、TikTok 的爆款视频里。个人看不到，不是因为信息不存在，而是因为：语言不通、渠道不熟、文化误读、没有一套可重复的发现与评估方法。

本项目把这件事工程化：先建立**人性需求（抱怨/希望/情绪/多巴胺/内啡肽）与文化差异**的扫描方法论，再建 **12 类信息差**的识别体系与 **10 维评分卡**，把公开信号变成带证据的机会卡；每个机会强制回答**商业驱动七问**（流量、钱、模式、ROI、人群、驱动、壁垒）；最后用**日/周/月/年四窗口榜单 + 14 个行业板块**的网页交付，配合「每周 1 个 7 天验证实验」把机会变成现金流。

v0.1.0 交付：**可离线双击打开的 8 页 Web 应用 + 40+ 条带证据的机会库 + 4 窗口榜单 + 12 个扫描剧本 + 60+ 平台数据源矩阵 + 13 份方法论/战略/技术/运营文档（00–12） + 可运行的 Python 扫描流水线 + 版本冻结发布体系**。自用优先，先跑通"发现→验证→赚钱→校准"闭环，再谈产品化。

## 4. 十个核心设计决策（为什么这样做）

| # | 决策 | 理由 |
|---|---|---|
| 1 | 不做"实时全网爬虫"，先做"离线数据 + 人工研究"的闭环 | 个人项目的瓶颈不是数据量，是判断质量与执行转化；先验证有人真的用 |
| 2 | 榜单窗口由扫描器计算并固化，前端只读 | 单一数据源，避免前后端两套规则不一致；历史可复现 |
| 3 | 证据分三层（一手/二手/营销稿） | 防假信号；营销稿不计入证据分 |
| 4 | 七问强制、证伪条件强制 | 答不上来的不是机会；没有退出条件的不是决策 |
| 5 | 信息差带半衰期与窗口状态 | 机会会过期，晚 6 个月可能从套利变内卷 |
| 6 | 10 维评分公开权重 + 可拖动演示 | 可解释、可争论、可校准；黑箱评分无法进步 |
| 7 | 数据/应用/文档三版本独立 | 应用升级不污染历史判断；数据契约变更必须显式升版 |
| 8 | 前端构建期打包数据、`base:'./'` + HashRouter | 保证 `file://` 双击可用，无服务器、无 CDN、无隐私风险 |
| 9 | 反直觉位 + 低资本位 + 编辑推荐位 | 防止榜单被热度和视觉冲击带偏；个人需要"能启动"而非"听起来牛" |
| 10 | 不承诺收益、不碰灰产/荐股；完整免责 | 伦理与合规是长期可信度的前提，也是最大的风险控制 |

## 6. 业务模式摘要（扫描器自己怎么赚钱）

| 阶段 | 时间 | 模式 | 收入目标 | 关键动作 |
|---|---|---|---|---|
| 0 自用 | 0–3 月 | 免费、只服务自己 | 0（赚自己的钱） | 跑通闭环：4 个实验（EXP-01~04）、至少 1 笔正现金流 |
| 1 订阅 | 3–6 月 | 周报 + 榜单 + 评分工具，¥99/月（年付 ¥999） | 90 天：付费 ≥3、MRR ≥¥300；**30–100 用户是 6–12 个月目标**（≈¥0.3–1 万/月） | 用真实结果做案例；不承诺收益 |
| 2 定制/陪跑 | 6–12 月 | 1v1 选题 + 验证陪跑，¥3000–10000/次 | 少量高客单 | 只接自己能验证的领域 |
| 3 社群/数据 | 12 月+ | 年度会员 + 机会年鉴 + 行业主题报告 | 订阅+一次性 | 校准数据库成为护城河 |

> 定价锚点：不是"多少条信息"，而是"帮你避免一次 5000 元的错误 / 省下 20 小时研究时间"。
> 底线：不卖焦虑、不荐股、不转售版权内容、不做"稳赚"承诺；自己没做过/没验证过的主题不写成报告。

## 8. 90 天启动路线（个人版）

| W6 | 复盘 + 内容化 | 把 2 个实验写成案例发出去；选 EXP-03 | 获得 3 个外部反馈 |
| W7–8 | 第三个实验（EXP-03） | 验证**渠道/合规**（投放、平台规则、资质） | 渠道成本/合规结论明确 |
| W9–10 | 第四个实验（EXP-04，可收费） | 预售/报价/收第一笔钱，验证支付链路 | 首笔正现金流（哪怕 100 元） |
| W11–12 | 校准 | 回测 ≥3 个实验：评分 vs 结果 | 调整 1–2 个维度权重 |

## 10. 主要风险与对策（Top 8）

| 风险 | 表现 | 对策 |
|---|---|---|
| 数据真实性 | 假信号、营销稿、编造数据 | 证据三层 + 三角验证 + `verified` 标记 + 红队抽查 |
| 合规 | 抓取违规、版权、宗教敏感、跨境限制 | 源分绿/黄/红 + 限速 + 免责 + 合规字段 |
| 执行转化 | 收藏夹吃灰、只看不做 | 核心 KPI = 每周验证数；7 天实验 + 止损线 |
| 评分失真 | 权威感过强、以分数代替判断 | 公开权重与锚点、可重算、季度回测、固定反直觉位 |
| 机会过期 | 老机会被当新机会 | 半衰期 + 窗口状态 + 过期下架 |
| 现金流 | 备货压款、账期、退款 | ROI 强制三档情景 + 现金流字段 + 组合管理 |
| 平台依赖 | 单一平台政策变化 | 多平台验证 + 平台风险标注 + 反直觉位 |
| 单人产能 | 机会太多、什么都想做 | 每周最多 1 个实验、观察池、季度聚焦 |

## 11. 怎么开始（5 分钟上手）

1. **打开**：双击 `releases/v0.1.0/dist/index.html`（或开发模式 `cd app; pnpm dev`）。
2. **看今天**：指挥台 → 日榜 Top5 → 点进最感兴趣的一个。
3. **做判断**：读七问与证据链 → 看 ROI 与风险 → 拖权重滑杆看它是否还排得上。
4. **开始验证**：照着「7 天验证动作」做，预算 ≤ 500 元，写下止损条件。
