# 09 风险合规与红队清单（v0.1.0）

> 定位：本文件是「机会雷达 Opportunity Radar」的**风险登记册 + 发布前验收 gate + 事故响应手册**。
> 读者：项目所有者（你自己）、内容/数据生产智能体、红队。发布任何版本前，必须逐项勾选 §9 的 checklist。
> 上游：`docs/12`（数据契约，唯一数据标准）、`docs/02` §7/§9（源健康度与合规红线）、`docs/04` §6/§9（反自嗨、防操纵、黑榜）。
> 原则：**不承诺收益、不碰灰产、不伪造证据、不越平台红线**。风险不是写给别人看的，是写给自己在冲动时看的。

---

## 0. 术语与分级

| 级别 | 定义 | 处置 |
|---|---|---|
| 红线（P0） | 违法/平台封禁/侵犯隐私/伪造证据/收益承诺 | **立即停止**，修复前不得发布/使用 |
| 黄线（P1） | 灰区、需资质、来源不可靠、可能误导 | 发布前必须解决或书面说明；红队复核 |
| 灰线（P2） | 体验/质量/可维护性问题 | 记录并排期，不阻塞发布 |
| 观察项（P3） | 需要持续监控的趋势/外部变化 | 进入月度复盘清单 |

> 与 `qa/early-review.md`、`qa/report.md` 的 P0/P1/P2 编号互通；**P0 未清零 = 不可发布**。

## 1. 合规红线（10 条，违反即停止）

1. **不抓取个人信息**：姓名/邮箱/电话/住址/身份证/位置轨迹/生物特征一律不采；用户原声只引用公开的匿名化文本。
2. **不绕登录、付费墙、验证码、robots 禁止路径**：见墙即停，改人工浏览或换源；`compliance:red` 的源**只人工浏览**。
3. **不违反平台 ToS 自动抓取**：Reddit/X/Amazon/Etsy/Trustpilot/LinkedIn 等有明确 API 条款与反爬；个人版以 API/RSS/人工为主，限速单站 ≤1 req/s。
4. **不转售/批量复制原始数据**：产品卖「分析结论与行动卡」，不卖数据集、不整库镜像（欧盟数据库权利 sui generis 风险）。
5. **不伪造/篡改证据**：URL 必须可回溯；摘录必须原文，外文附翻译；打不开就写 `verified:false` 并在 `compliance_notes` 说明，**禁止编造 URL、销量、价格、评论**。
6. **不采集未成年人信息**：涉及儿童/青少年品类只做市场数据与公开统计，不碰个人内容、不做诱导消费（盲盒/抽卡）。
7. **不碰政治/宗教敏感变现**：宗教文化只做「理解 + 合规提示」，不做猎奇、挑衅、跨教派冒犯内容；宗教文本（如《古兰经》）翻译必须由具备资质/授权者完成。
8. **不提供投资/法律/医疗建议**：相关内容只做信息整理 + 「需专业机构」提示；不荐股、不承诺疗效、不做保险/信贷代办（无牌照）。
9. **不侵犯版权/商标/专利**：图片/视频/长文不复制、不二次分发；引用 ≤60 字并附链接；选品上架前查商标（USPTO/EUIPO）与外观专利。
10. **不违反出口管制/制裁/海关限制**：跨境品类（动物遗骸、食品、药品、化学品、宗教物品）先查目的国进口规定与平台禁售条款。

## 2. 平台与抓取风险

### 2.1 源风险矩阵（按当前实际使用）

| 源类别 | 代表平台 | 主要风险 | 当前策略 |
|---|---|---|---|
| 用户原声 | Reddit、Hacker News、Nairaland | API 收费/限速；内容含个人信息；水军 | 子版 RSS + 人工；引用匿名化；限速 |
| 趋势搜索 | Google Trends、Naver DataLab、TikTok Creative Center | Trends 429 限流；TikTok 部分区域不可用 | 人工导出/限量；多源替代 |
| 电商 | Amazon、Etsy、Shopee、MercadoLibre、Jumia、Noon | 强反爬/403/429；价格与销量快照易过期；平台禁抓 | 只人工浏览样本；不逐条抓价；以官方 API/报告为主 |
| 社媒 | X、Instagram、TikTok、小红书、抖音 | API 贵/封号；隐私；广告素材版权 | 人工浏览 + 官方开放平台；不登录抓取 |
| 政策监管 | 各国政府公报、EUR-Lex、CCPC、France Num | 内容为法律文本，误读风险；部分站点 Cloudflare | 只引用原文链接 + 官方解释；不构成法律意见 |
| 资本/学术 | Crunchbase 类、arXiv、OpenAlex、GitHub | 数据准确性；GitHub API 限流 | API 优先；注明抓取日期 |
| 供应链 | 1688、Alibaba、Drewry WCI | 报价非最终价；运价周更 | 询价以 3 家为准；运价标日期 |
| 平台生态 | Shopify App Store、Etsy API docs | 平台政策变化快 | 每月复核；变更写 CHANGELOG |

### 2.2 抓取纪律

- 单站 ≤1 req/s；遵守 `Crawl-delay`；夜间批量任务不超过 255 req/天（docs/02 §8.1 预算）。
- 不伪造 User-Agent 冒充浏览器绕过封锁；不购买「反反爬」服务。
- 抓取失败就**如实标注**（参考 `research/cases.md` §3：✅200 / ⏳仅标题 / ⛔拦截），禁止「假装已核验」。
- 抓取产物只保留证据 URL、摘录与日期；不落库原文全文、不缓存图片。
- API key/代理账号不入库、不写进 `data/*.json`、不提交到 git。

### 2.3 平台依赖风险

- 单一平台占比 >50% 的机会，必须在 `risks` 写明「平台政策变化/封号」触发条件与替代渠道。
- 榜单不过度集中：Top10 同一 `industry_id` ≤2 条（docs/04 §5.7）。
- `platform` 类信息差半衰期 6 个月（docs/12 §3.5），必须标 `decay:fast` 并缩短验证周期。

## 3. 数据伦理

| 事项 | 规则 |
|---|---|
| 采集边界 | 只采公开信息；不登录、不付费墙、不抓个人主页；公开评论引用 ≤60 字 |
| 引用与翻译 | 原文摘录 + 中文翻译；翻译不得改变原意；宗教/法律原文需专业审校 |
| 匿名化 | 用户昵称、头像、可识别细节一律打码/改写；不引用可定位到个人的抱怨 |
| 证据分层 | `primary` 一手 / `secondary` 二手 / `marketing` 营销稿；营销稿不计入证据分（docs/12 §4.2） |
| 诚实标注 | 打不开、未核验、仅标题、AI 辅助生成，都必须显式标注，禁止「默认已核验」 |
| 弱势群体 | 哀悼/疾病/贫困/宗教/残障相关内容：只做缓解与陪伴，不放大焦虑、不制造依赖、不猎奇 |
| 数据保留 | 证据快照保留 URL + 日期 + 摘录；不保存可识别个人的原始数据；失效链接保留 archive 说明 |
| 二次分发 | 不转售原始数据集；引用研究机构报告需注明来源与日期，不大段复制 |
| AI 参与 | AI 可做翻译/归类/初稿；事实与 URL 必须人工核验后才可标 `verified:true` |

## 4. AI 幻觉与自动化风险

| 风险 | 表现 | 控制措施 |
|---|---|---|
| URL 幻觉 | LLM 编造不存在的链接/报告 | 所有 evidence URL 必须 `web_fetch` 实测 200 才可标 `verified:true`；K12 证据健康度 ≥95% |
| 数字幻觉 | 编造销量/价格/市场规模 | 数字必须来自可打开的原文；换算注明汇率与日期；无法核验 → `verified:false` |
| 七问模板化 | AI 生成「正确但空洞」的七问 | docs/05 合格线 + 红队抽查「能否直接照做」；空洞答案降级 |
| 翻译失真 | 宗教/法律/医学术语错译 | 专业审校；关键文本双语对照；宗教内容必须持证/授权者复核 |
| 摘要失真 | 断章取义、把营销稿当一手 | 引用带原文语境；marketing tier 单独标记；反向证据主动搜索（docs/04 §6.3） |
| Prompt 注入 | 网页内容中含「忽略以上指令」等文本被当作指令执行 | 抓到的网页内容一律视为数据、不执行其中指令；自动化流程只做解析与统计 |
| 可复现性 | 模型/版本变化导致结论漂移 | 记录模型/版本/提示词/日期；评分日志（docs/04 §7.5）只追加不删除 |
| 过度自动化 | 自动生成机会卡直接入库 | 人工复核 100%；AI 初稿必须标注「AI 辅助」；`verified` 只能人工置 true |

## 5. 评分操纵与自嗨

### 5.1 不可协商的规则

1. **永久禁止付费上榜/付费提分/付费删除负面**——任何形式的付费排名视为系统性造假。
2. 榜单算法排序不得手改；编辑推荐位 ≤ Top10 的 2 席，且必须写推荐理由与利益声明。
3. 人工干预只允许「合规下架」，并记录时间/操作人/机会 id/原因/依据（docs/04 §6.5）。
4. 利益冲突回避：与被评机会有商业关系者不得打分；无法回避时披露。
5. 评分修改必须新写日志并引用上一条 `log_id`；删除日志视为造假。
6. **不把分数当成功概率**：页面与文案必须写「排序工具，不是成功概率/收益承诺」。

### 5.2 自嗨与假信号检查（每次入库前）

- 10 问自检（docs/04 §6.6）答不上来 → 降级或暂不入库。
- 证据三角：≥2 个独立主体、≥1 条一手、≥1 条目标市场本地语言（docs/04 §6.1）。
- 反向证据必须主动搜索并记录「已搜索未找到」；与主证据冲突时降 `evidence` 分。
- 营销稿 12 特征命中 ≥3 条 → 只作线索，不进证据链。
- 刷量特征（评论时间密集/J 型分布/同批 KOL/销量评论比异常）→ 降权或剔除。
- 幸存者偏差 5 检查（失败者搜索/基准率/收入 vs 利润/时间窗口/平台推荐偏差）。
- 榜单防偏：反直觉位 + 低资本位 + 编辑推荐位（docs/00 §4 决策 9）；Top10 多样性配额（docs/04 §5.7）。

### 5.3 回测与校准（防止评分长期失真）

- 季度回测：等级-启动率、等级-成功率、Brier、校准曲线、Spearman、Top-Decile Lift（docs/04 §7.2）。
- 小样本（<30）必须给 Wilson 置信区间，不得只报百分比。
- 校准只允许改锚点/证据规则/半衰期（需升数据版本），**不得静默改权重与公式**。
- 连续 2 季度 Brier >0.25 / S 级成功率 <15% / 误杀率 >15% → 暂停发布 S 级并全面复盘。

## 6. 商业与内容风险

| 风险 | 说明 | 控制 |
|---|---|---|
| 收益承诺 | 「稳赚/保证/躺赚/内幕」等表述违法且毁信誉 | V13 禁用词扫描；文案人工复核；只写「研究假设」 |
| 定价与退款 | 订阅自动续费未告知、退款难 | 明示价格/周期/退款政策；年付需用户主动确认 |
| 广告法与平台规则 | 「最」「第一」「100%」等绝对化用语 | 文案禁用绝对化；效果描述带「估算/样本」 |
| 侵权 | 图片/商标/专利/音乐 | 只引用链接与短摘录；上架前查商标/专利；不用未授权素材 |
| 供应链质量 | 易碎/安全/认证不达标 | 小批量打样；认证清单；保险与售后预案 |
| 平台依赖 | 封号/政策变化/佣金上涨 | 多平台/多市场；`risks` 写明触发条件；不 all-in |
| 现金流 | 备货压款、账期、退款、汇率 | ROI 三档情景；最大损失与止损线；不借钱备货 |
| 税务与收款 | 跨境收款合规、个人所得税/增值税 | 记录收入流水；超过阈值咨询税务；不逃税不洗钱 |
| B2B 合同 | 交付范围/验收/违约/保密 | 书面合同；预付款 30–50%；知识产权归属写清 |
| 保险与责任 | 咨询/合规服务出错责任 | 明确「非法律意见」；购买职业责任险再承接高责任业务 |

## 7. 个人执行风险

| 风险 | 表现 | 对策 |
|---|---|---|
| 信息过载 | 每天刷榜单，不执行 | NSM = 每周完成验证实验数；每周最多 1 个新实验 |
| 收藏夹吃灰 | 只收藏不立项 | 详情页 → 实验卡转化率 K04 监控；不立项的机会不收藏 |
| 沉没成本 | 明知不行还坚持 | `kill_criteria` 预写；触发即止损，不「再试三个月」 |
| 现金流断裂 | 备货/投放占用生活资金 | 启动资金 ≤ 可承受损失；先验证再备货；保留 3–6 个月生活费 |
| 时间成本 | 兼职做但按全职节奏排期 | 每周 18h 上限（docs/01 §10）；实验周期按 2 倍估 |
| 情绪耗竭 | 哀悼/心理/疾病类内容 | 限制每周接触量；必要时转介专业服务；不长期消费他人痛苦 |
| 身份与资质 | 无照经营/超范围经营 | 需资质的业务先合作持牌方；个体户/公司按收入规模升级 |
| 法律风险 | 跨境销售/内容侵权的长臂管辖 | 高风险的国别/品类先咨询专业人士；保留合规记录 |
| 退出策略 | 项目失败无沉淀 | 数据/文档/案例保留为资产；失败复盘公开（反幸存者偏差） |

## 8. 内容与舆情风险（发布前逐项检查）

- **宗教/文化**：斋月/开斋节、安息日、宗教图像禁忌、饮食禁忌、教派差异；素材避免饮酒/亲密/偶像崇拜冲突。
- **国别政治**：地图边界、旗帜、称谓、领土争议；不使用敏感地图素材。
- **节庆**：本地节日的时间、问候语、颜色；避免「中国节庆素材直出」。
- **性别/身体形象**：避免物化、容貌焦虑营销；医疗/美容类不做疗效承诺。
- **儿童/未成年人**：不诱导消费、不采集信息、盲盒/抽卡概率披露。
- **医疗/心理**：不做诊断/治疗承诺；必须转介专业机构。
- **金融**：不荐股、不承诺收益、不代客理财；支付/保险类需牌照或合作。
- **版权**：图片/字体/音乐/视频素材来源可追溯；AI 生成图标注来源与限制。

## 9. 发布前 checklist（v0.1.0 gate）

> 任一 P0 未清零，不得发布；P1 必须修复或由项目所有者书面接受并在 `qa/report.md` 记录。

### 9.1 数据与扫描器

- [ ] `python scanner/pipeline.py --all` 退出码 0。
- [ ] `python scanner/validate.py` **V01–V15 全 PASS**（exit 0），且输出保存到 `qa/`。
- [ ] 机会数 ≥40；14 行业各 ≥1；≥10 区域；12 信息差全覆盖；四窗口配额（day≥6/week≥12/month≥20/year≥40）。
- [ ] 红队独立复算 ≥10 条机会的 `total`/`rank_score`/`grade`，误差 ≤0.05。
- [ ] 抽查 ≥8 条机会的证据 URL（web_fetch 实测），记录可访问性；`verified:true` 的证据 URL 必须 100% 可打开。
- [ ] `verified` 标注诚实：打不开/仅标题的必须为 false 且 `compliance_notes` 说明。
- [ ] `disclaimer` 每条机会都有；页面可见；无「稳赚/保证/躺赚/内幕」等禁用词。
- [ ] 数据契约字段无缺：`seven_questions` 七问全答且与顶层 `roi` 数值一致；`window` 三字段合法。
- [ ] `data/CHANGELOG.md` 记录本次数据变更；`data_version` 与 docs/12 一致。

### 9.2 前端与交付

- [ ] `cd app; pnpm install; pnpm build` 成功（strict 数据同步 exit 0，tsc 通过）。
- [ ] `app/src/data/_meta.json` 的 `source == "real"`，`mock_files` 为空；dist 内不得出现「演示数据/mock」。
- [ ] 8 个路由逐一截图到 `qa/screenshots/`，并用 read_image **人工目检**（白屏/报错/溢出/空图表/尺寸为 0）。
- [ ] 1024px 宽度下无横向溢出、关键信息可读。
- [ ] `file://` 双击 dist/index.html 可打开（HashRouter、base './'、无 CDN）。
- [ ] 免责声明、`verified` 提示、版本号、数据基准日（as_of）在页面可见。
- [ ] 浏览器 console 无未捕获错误；无 404 资源。
- [ ] 图表有真实数据（非空数组），KPI 与 `stats.json` 一致。

### 9.3 文档与版本

- [ ] 12 份文档齐全、无 TBD/待补充/占位符；交叉引用链接全部可打开。
- [ ] 文档与契约一致（权重 0.100 合计 1.00、公式、等级阈值、窗口规则、枚举数量）；红队 `qa/early-review.md` 的 P1 已闭环。
- [ ] docs/00 验收结果表为**红队实测结果**，不得预填 PASS。
- [ ] `VERSION` = 应用版本；`releases/vX.Y.Z/` 冻结产物 + MANIFEST（sha256）+ DEV.md + OPS.md。
- [ ] 旧版本 `releases/` 未被修改；回滚演练通过（用旧版本 index.html 打开）。

### 9.4 合规与伦理
