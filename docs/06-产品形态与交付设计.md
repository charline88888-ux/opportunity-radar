## 0. 一页定位

| 维度 | 定义 |
|---|---|
| 一句话 | 每天早上 3 分钟，看全世界昨天新冒出来的赚钱信息差，并知道「我这种人现在能不能做、第一步做什么」。 |
| 形态 | 本地单页 Web 应用（离线双击可用）+ 可导出的日报/周报/月报/年鉴 |
| 核心对象 | 「机会卡」：一条有证据、有评分、有七问答案、有 7 天验证动作的商机假设 |
| 核心指标 | **执行验证数**（每周完成 7 天实验的数量）＞ 首个正现金流项目数 ＞ 机会库规模 |
| 反指标 | 收藏数、页面浏览量、机会总数——这些涨了但没行动，等于零 |
| 使用节奏 | 日榜 3 分钟扫、周榜 20 分钟复盘、月榜 60 分钟选题、年鉴 2 小时定全年方向 |
| 不做什么 | 不做荐股/炒币/灰产信息；不做「稳赚项目」；不做需要专业牌照才能做的投资建议 |

## 1. 产品原则（设计决策的最高依据）

1. **Local-first（本地优先）**：所有数据、评分、页面都在本机；`file://` 双击可开，不需要服务器、账号、联网。隐私即护城河。
2. **Evidence-first（证据优先）**：每条机会必须能点回原始来源；没有证据的洞察只能进「假设池」，不能进榜。
3. **Seven-question（七问强制）**：流量、钱、模式、ROI、人群、驱动、壁垒，答不全的不展示为「机会」，只展示为「线索」。
4. **Action-first（行动优先）**：每个机会必须有 `first_steps_7d` 与 `kill_criteria`；详情页的 CTA 是"开始 7 天验证"，不是"收藏"。
5. **Contrarian-friendly（反共识友好）**：榜单刻意保留低热度但信息差大的 B 级机会，避免只奖励"已经很火"的东西。
6. **Calibration over hype（校准高于热度）**：评分可以错，但必须记录预测与结果，按季度回测校准（见 docs/04）。
7. **Immutable releases（版本不可变）**：每次升级冻结一个新版本目录，旧版本永远能打开（见 docs/10）。

## 2. 信息架构

```
机会雷达
├── 指挥台 Dashboard        # 今天有什么值得看（3 分钟）
├── 排行榜 Rankings         # 日/周/月/年 × 行业板块 × 信息差类型
│    └── 机会详情 Detail     # 一条机会的完整尽调页 + 权重模拟
├── 扫描室 Scanner          # 我怎么自己扫（剧本、需求矩阵、源健康度）
├── 方法论 Method           # 为什么这样评分、七问、文化差异
├── 数据源 Sources          # 平台矩阵与合规
├── 商业日历 Calendar       # 提前 3-6 个月布局的节点
└── 关于 About              # 版本、免责、路线图
```

三层信息密度：

| 层 | 位置 | 信息量 | 目标 |
|---|---|---|---|
| L0 扫一眼 | 指挥台、榜单卡片 | 标题 + 总分 + 行业 + 一句话 | 3 秒判断要不要点开 |
| L1 快速判断 | 卡片展开、榜单表格 | 七问摘要 + ROI + 证据数 | 30 秒判断值不值得验证 |
| L2 尽调 | 机会详情 | 七问全文 + 证据链 + 风险 + 7 天动作 | 10 分钟决定做不做 |
| L3 执行 | 导出/打印/实验追踪 | Markdown 机会卡 + 检查清单 | 落地验证 |

## 3. 榜单体系（产品的心脏）

### 3.1 四个窗口

| 榜单 | key 规则 | 回答的问题 | 阅读场景 |
|---|---|---|---|
| **日榜** | `last_activity == as_of`（今天有新信号/新证据） | 今天世界上又冒出了什么？ | 每天 07:30 早报，3 分钟 |
| **周榜** | `last_activity` 落在当前 ISO 周（2026-W43） | 这周哪些机会在加速、哪些新上榜？ | 周日复盘，20 分钟 |
| **月榜** | `last_activity` 在当月（2026-10） | 这个月的主题是什么？该启动哪个实验？ | 每月 1 日选题，60 分钟 |
| **年榜** | `last_activity` 在当年（2026） | 全年哪些机会真的值得重注？ | 12 月做年度规划，2 小时 |

窗口归属由扫描器计算并写入 `data/rankings.json`，前端只读不重算（保证榜单唯一权威）。

### 3.2 排序与标记

- 排序键：`rank_score`（总分 × 动量调整），降序；同分依次比较 `momentum`、`evidence_count`、`last_activity`。
- 展示标记：`NEW` 新上榜（上期不在榜）、`↑n` 上升、`↓n` 下降、`—` 持平；S/A/B/C 等级色。
- 「榜单解读」区：每天/周自动生成 3 条摘要（由 stats.json 聚合 + 编辑撰写），例如「本周最明显的变化：中东宗教教育内容需求上升 3 位，来自 2 个新证据源」。
- **编辑推荐位**：算法榜之外保留 1-3 个「编辑选择」，人工权重与算法权重分离展示，避免纯热度导向；编辑推荐必须写理由。
- **反直觉位**：固定保留一个「低热度高信息差」席位（rank 不高但 gap + evidence 高分），防止榜单变成追热点。

### 3.3 行业板块榜（14 个）

- 榜单页顶部行业 chip（14 个，来自 taxonomy），点击后只保留该行业机会，同时显示「该行业本月 Top3」。
- 每个行业有独立小榜：`/rankings?industry=mena` 之类状态可分享（HashRouter query 保留）。
- 行业空数据时显示"该行业本期暂无新信号 + 最近一次上榜机会"，不显示空白。

### 3.4 榜单发布节奏（自用版）

| 时间 | 动作 | 产出 |
|---|---|---|
| 每日 07:00 | 扫描器增量跑批（或手动 `--all`） | 更新 rankings/stats |
| 每日 07:30 | 打开指挥台看日榜 Top5，写 1 行「今日观察」 | 日报（3 分钟） |
| 每周日 20:00 | 周榜复盘 + 选 1 个机会做 7 天实验 | 周报（20 分钟） |
| 每月 1 日 10:00 | 月榜 + 行业板块复盘 + 决定本月主攻方向 | 月报（60 分钟） |
| 每年 12 月 | 年榜 + 年度机会年鉴 + 下一年 3 个方向 | 年鉴（2 小时） |

> v0.2 起可接 Windows 任务计划程序自动跑批；v0.1.0 手动跑 `python scanner/pipeline.py --all`。

## 4. 机会卡片规范（L0/L1）

```
┌──────────────────────────────────────────────────────────────┐
│ [宠物经济]  A 级 78.9  ↑2   NEW        [跨境][低资本][可兼职] │  ← 行业/等级/分数/变化/标签
│ 宠物离世纪念玻璃摆件：把骨灰/毛发封进玻璃的定制生意            │  ← 标题（≤28字，说清谁为什么付钱）
│ 欧美宠物殡葬情绪消费升级，客单 $120–400，独立站即可验证         │  ← 一句话（≤60字，含验证点）
│ ─────────────────────────────────────────────────────────── │
│ 信息差：文化/宗教差 + 情绪差   窗口：开放 18 个月   证据 3 条  │  ← 关键判断信息
│ 启动 3–8k 元｜回本 5 个月｜毛利 65%｜兼职可做                  │  ← 商业化速览（来自 ROI）
│ 七问：流量✅ 赚钱✅ 模式✅ ROI✅ 人群✅ 驱动✅ 壁垒⚠️          │  ← 七问完整度（壁垒弱要显式提示）
└──────────────────────────────────────────────────────────────┘
```

卡片必须遵守：

- 标题不许写成"XX 行业分析"，必须是「**谁 / 为什么 / 付多少钱 / 你能怎么切入**」。
- 一句话里必须出现至少一个**可验证数字**（价格、规模、增速、客单、回本）。
- 七问完整度用 ✅/⚠️ 展示；缺项不能隐藏，缺项说明"为什么缺"。
- 卡片 hover：显示证据来源数、首次发现日期、窗口状态；点击进详情。
- 表格视图：列 = 排名、标题、行业、等级、总分、动量、启动资金、回本、窗口、证据数、更新时间；可排序。

## 5. 机会详情页（L2）

七个区块，顺序即决策顺序：

1. **头部**：标题 + 一句话 + 行业/区域/信息差/需求/情绪标签 + 总分/等级/排名 + 窗口状态 + "加入实验"按钮。
2. **七问全景**：7 张卡，每张含问题、答案、质量标记（✅/⚠️）；`drivers` 用 7 个驱动徽章（资本/技术/信息/跨国/政策/运营/供应链）；`roi` 用 4 个数字卡（启动资金/回本月数/月收入区间/毛利率）。
3. **评分解释**：10 维雷达 + 每维分数条 + 一句话「为什么不是 S」+ 证据可信度说明；**权重滑杆**（演示模式：拖动 10 个权重，实时重算总分并显示 Top10 重排，公式与契约一致）。
4. **证据链**：evidence 列表，每条含 tier 徽章（一手/二手/营销）、日期、来源、摘录、外链；`verified:false` 的条目显著提示"未二次核验"。
5. **行动区**：7 天验证动作（可勾选的 checklist，状态存 localStorage）、一周预算、需要的资源、成功/失败判定（kill_criteria）。
6. **风险与合规**：risks 列表 + compliance_notes + 平台/法规提示 + 免责声明。
7. **延展**：同需求/同区域/同信息差的相关机会（3-5 条）+ 数据出处 + 更新历史（activity_dates 时间轴）。

交互约定：

- 所有外链 `target="_blank" rel="noopener"`。
- checklist 勾选状态本地持久化（localStorage），不依赖后端。
- 详情页可直接导出 Markdown 机会卡（复制到剪贴板），字段齐全，便于打印/发给合作者。
- 无数据字段降级：显示"未提供"而不是空白或报错。

## 7. 交互与状态

- **筛选**：行业（14）、信息差（12）、区域（11）、等级（S/A/B/C）、窗口状态（open/peak/closing）、标签（20）；筛选条件写入 URL query（HashRouter），可刷新保持。
- **排序**：综合分 / 动量 / 证据数 / 启动资金 / 回本周期 / 更新时间。
- **搜索**：标题 / 一句话 / 标签 / 国家 模糊搜索（前端本地）。
- **个人画像**（v0.1.0 简版）：资金档位（<1 万 / 1–5 万 / 5–20 万 / 20 万+）、每周可投入小时数、是否有供应链、英语水平、风险偏好；用于榜单重排（前端 localStorage 记忆，公式见 docs/04）。
- **实验看板**（v0.1.0 轻量）：勾选"加入实验"后，本地记录机会 id、开始日期、状态（进行中/已验证/已放弃）、一句话结论；指挥台显示"进行中实验 N 个"。
- **状态**：加载骨架屏（skeleton）、空数据、部分字段缺失、数据过期（as_of 超过 7 天显示"数据可能过期，请重跑扫描"）。
- **导出**：机会卡 Markdown、榜单 CSV、当前视图打印（PDF）。

## 8. 交付物形态（年/月/周/日）

### 8.1 日报（3 分钟，每天 07:30）

```
【机会雷达·日报 2026-10-22】
今日新信号 6 条｜新上榜 3 条｜A 级以上 2 条
1. [A 78.9] 宠物离世纪念玻璃（宠物/文化差）启动 3–8k｜回本 5 个月
2. [B 71.2] 沙特斋月企业礼赠定制（文化/宗教差）…
3. …
今日观察：中东宗教内容相关信号连续 3 天出现，值得留意。
行动建议：从 Top1 开始做 7 天验证（预算 ≤ 500 元）。
```

### 8.2 周报（20 分钟，周日）

- 本周新机会 Top5、上升最快 3 条、掉出榜单 2 条及原因；
- 本周实验复盘（做了什么、花了多少、得到什么结论）；
- 下周 1 个实验选题 + 预算 + 止损线；
- 数据质量：本周新增证据数、失效源提醒。

### 8.3 月报（60 分钟，每月 1 日）

- 月榜 Top10 + 行业板块热度变化；
- 本月主题（例如"中东文化合规"）深度 2 页；
- 实验组合复盘：投入/产出/时间；有效/无效假设归档；
- 下月主攻方向与预算上限；评分权重是否需要调整（记录理由）。

### 8.4 年鉴（2 小时，12 月）

- 年榜 Top20 + 消失的机会（过期/被证伪）复盘；
- 12 个月主题演化时间线；
- 个人能力/资源变化；
- 下一年 3 个方向 + 每个方向的季度里程碑；
- 评分模型年度校准报告（预测 vs 实际）。

> v0.1.0 先生成 Markdown/HTML 模板（在详情页可复制），v0.2 起自动从数据生成报告文件。

## 10. 设计语言（v0.1.0 实现约束）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0a0c10` | 页面底色 |
| `--panel` | `#12151c` | 卡片/面板 |
| `--panel-2` | `#171b24` | 悬浮/二级面板 |
| `--border` | `#232936` | 细边框 |
| `--text` | `#e6e9f0` | 主文字 |
| `--muted` | `#8b93a7` | 次文字 |
| `--signal` | `#3ddc97` | 正向/信号/青绿 |
| `--amber` | `#ffb547` | 提醒/机会/窗口 |
| `--cyan` | `#4cc9f0` | 信息/链接 |
| `--red` | `#ff5d5d` | 风险/下降/警示 |
| S/A/B/C/D | `#ffd166 / #3ddc97 / #4cc9f0 / #8b93a7 / #5a6273` | 等级色 |

- 字体：`Inter, "PingFang SC", "Microsoft YaHei", system-ui`；数字 `font-variant-numeric: tabular-nums`；标题字重 600，正文 400/13–14px。
- 布局：左侧 220px 导航 + 主内容 12 栅格；内容最大宽度 1600px；卡片间距 12/16px；圆角 10–12px。
- 动效：150–250ms ease-out，仅用于 hover、页面切换、榜单重排（framer-motion layout）；不做装饰性大动画。
- 禁用：紫蓝渐变大标题、玻璃拟态泛滥、发光边框、3D 图表、自动轮播。
- 图表一致性：ECharts 主题与 token 对齐；网格线低对比；legend 在顶部左侧。

| 规则 | 触发条件 | 严重度 |
|---|---|---|
| 窗口关闭 | `window.months_left ≤ 3` 且未关闭 | 高 |

| 采集源失败 | `source-health.sources[].ok = false` | 中 |
| 未核验证据 | `verified=false` 且等级 S/A | 中 |
| 高匹配未行动 | `fit ≥ 0.75` 且未加入实验 | 低 |
