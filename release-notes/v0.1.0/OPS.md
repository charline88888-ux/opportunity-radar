## 7. 下一版运营动作（v0.2.0）

1. 启动 EXP-01（建议从 A 级 + 低资本 + 可远程机会中选），预算 ≤500 元，7 天结案并回填结论。
2. 每周补 2–3 条新机会，优先非英语市场（MENA/东南亚/拉美）。
3. 对 41 条 `verified:false` 机会做批次核验（每周 5 条），更新 verified 与 compliance_notes。
4. 建立「实验日志」表（机会 id / 预算 / 耗时 / 结果 / 结论），为 v0.2 的回测校准提供样本。
5. 数据源月检：抽检 5 个源，更新 `sources.json` 健康度与 `research/platform-matrix-validation.md`。
6. 每月发布 1 次 PATCH/MINOR，按 `docs/10` 流程冻结，不覆盖 v0.1.0。
