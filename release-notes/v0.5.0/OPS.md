# v0.5.0 运营文档（OPS）

> 版本：v0.5.0　｜　数据版本：data-v0.5.0　｜　日期：2026-10-22　｜　线上：https://charline88888-ux.github.io/opportunity-radar/

## 1. 本版运营重点
- **年度复盘**：12 月打开 `/yearbook` 过一遍年榜/月度时间线/A 级清单/窗口关闭机会；导出年鉴归档；需要打印版跑后端 yearbook.py。
- **数据备份/迁移**：`/data` 导出个人数据包（画像/实验/预警/推荐记录），换设备导入；建议每月备份一次。
- **推荐漏斗**：每月看曝光→查看→实验→命中率；命中率低调整画像或推荐阈值，忽略多说明推荐不匹配。
- **i18n 残差**：英文界面抽查（UI 全英、数据中文有标注）；发现未译 UI 记入下周修复。
