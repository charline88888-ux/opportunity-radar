# v0.8.0 运营文档（OPS）

> 版本：v0.8.0　｜　数据版本：data-v0.8.0　｜　日期：2026-10-23　｜　线上：https://charline88888-ux.github.io/opportunity-radar/

## 1. 本版怎么用
1. 双击 `启动机会雷达.bat` → 控制台 → 「采集收件箱」；
2. 默认看「相关+新增」：本轮 business 184 条（共 1,015 条信号），可按行业/区域筛；
3. 「扫描边界与漏斗」看你扫了多少源/失败源/规则/未覆盖平台；
4. 选信号 → 人工复核成机会卡 → 入库 → 更新数据；排行榜只显示入库机会。

## 2. 重复与新鲜度
- 跨批账本：同一 feed 旧条目只算「已见」，重复跑 new_count 会归零（正常）；
- 每天采集会累积新信号；想扩源改 `data/sources.json`（enabled/priority/url）后重新 fetch；
- 源失败先看 source-health，再决定修 URL/换源/停用。

## 3. 边界（务必知道）
- 自动源 57（RSS/JSON/新闻聚合）；125 目录里其余是人工/API/需授权；
- 只抓标题/摘要/链接，不抓正文、评论、付费墙、登录页、JS 渲染内容；
- 社交平台、电商站内趋势、付费报告不在自动范围；
- 信号不是机会：必须人工复核入库后才会评分上榜。
