# v0.7.3 运营文档（OPS）

> 版本：v0.7.3　｜　数据版本：data-v0.7.0　｜　日期：2026-10-23　｜　线上：https://charline88888-ux.github.io/opportunity-radar/

## 1. 现在「采集」到底做了什么
- 采集 = 从 8 个公开源抓原始信号（今天 185 条 → 去重后 183 条），写入 `scanner/outbox/signals-<date>.json`；
- **不会自动变成机会**：需人工复核（enrich 草稿 + 判断）后才写入机会库；这是质量闸门；
- 「今日 0 机会」是正常：今天没有新机会入库，机会库 80 条历史机会仍可看；控制台「采集收件箱」能看到 183 条待复核信号。

## 2. 每天怎么用
1. 双击 `启动机会雷达.bat` → 控制台；
2. 看「采集收件箱」→ 挑信号（Top 标题/来源）；
3. 「立即更新数据」→ 刷新榜单（当天没有新机会时 day=0，属正常）；
4. 选中信号后按 docs/08 的复核流程补机会卡（七问+证据），再更新。

## 3. 常见问题
- 页面显示今天 0 机会：正常，不是采集失败；看收件箱与 `scanner/outbox/`。
- 收件箱为空：还没点「立即采集」，或采集失败（看日志/source-health）。
- 采集日期不对：v0.7.3 起 `--fetch --as-of` 与控制台自动用当天；旧文件可能仍显示 10-22。
