# v0.4.0 运营文档（OPS）

> 版本：v0.4.0　｜　数据版本：data-v0.4.0　｜　日期：2026-10-22　｜　线上：https://charline88888-ux.github.io/opportunity-radar/

## 1. 本版运营重点
- **双语对外**：分享给英文用户时切 EN（UI 英文，机会内容仍中文并标注），不要假设数据已英译。
- **AI 富化每日 SOP**：`--fetch` → `python scanner/enrich.py` → 读 `scanner/outbox/REVIEW.md` → 人工复核 → 手工写机会卡入库；**任何富化结果不得直接入库**。
- **校准常态化**：每月/每年从 `/calibration` 导出实验 JSON → `python scanner/calibrate.py --experiments 文件` → 归档 `data/reports/calibration-*.html`；样本 <3 只看不调。
- **通知可选**：`/alerts` 开桌面通知（需授权；不支持自动降级）。

## 2. 日常节奏（v0.4.0）
| 节奏 | 动作 |
|---|---|
| 每日 07:00 | 定时任务 `--all`（+可选 `--fetch`） |
| 每日 07:30 | `/alerts` 处理高严重度 + 「高匹配未行动」 |
| 每日 10 分钟 | outbox 复核（enrich 候选 → 人工判断） |
| 每周日 | 实验结案（写 outcome）→ 看 `/calibration`；跑周报 |
| 每月 1 日 | calibrate 报告归档 + 月报复盘 |
| 每年 12 月 | 年度实验导出 → calibrate 年度报告 → 年鉴 |
