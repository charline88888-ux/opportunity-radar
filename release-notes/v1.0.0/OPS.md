# v1.0.0 运营文档（OPS）

> 版本：v1.0.0　｜　数据版本：data-v1.0.0　｜　日期：2026-10-23　｜　线上：https://charline88888-ux.github.io/opportunity-radar/

## 1. 使用（极简）
1. 打开线上或本地冻结版；
2. 看「商机榜」日榜（周/月/年切换）；
3. 点候选看中文标题、来源、七问草稿、评分；精选机会可筛选查看；
4. 不需要设置画像、不需要验证、不需要实验；系统每天自动扫描入榜。

## 2. 每日更新
- 线上：GitHub Actions 每天 06:30（北京时间）自动 fetch→评估→榜单→部署；
- 本地：可选 `scripts/daily-run.ps1`（需 Python/pnpm）或直接使用最新冻结版；
- 无需本地控制台/服务。

## 3. 边界
- 系统只负责发现与评估，不验证个人能否赚钱、不承诺收益；
- 候选为公开信号线索，使用前自行核对来源；
- 自动源 101/168，社交平台/电商站内/付费内容不在自动范围。
