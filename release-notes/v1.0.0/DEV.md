# v1.0.0 开发文档（DEV）

> 版本：v1.0.0（MAJOR）　｜　数据版本：data-v1.0.0　｜　日期：2026-10-23　｜　上一版：v0.9.2

## 1. 为什么做这次重构
用户明确要求回归第一版边界：**只做每天扫描、评估商机、入榜**。验证/实验/校准/画像/预警/年度/数据包/控制台等被判定为偏离主线的“乱七八糟功能”，全部移除；系统不验证个人商业结果、不承诺盈利。

## 2. 保留
- 扫描：101 自动源 / 168 平台 / 11 区域；源健康度、漏斗、XML 容错、跨批去重。
- 评估：候选 200 条（七问草稿、ROI 估算、10 维评分、中文标题、系统评估 high/medium/low）；精选 80 条机会卡。
- 榜单：商机榜日/周/月/年（自动候选全部入榜 + 精选标签）。
- 页面（9）：指挥台 / 商机榜 / 候选详情 / 精选机会详情 / 扫描室 / 方法论 / 数据源 / 商业日历 / 关于。
- 每日自动化：Actions fetch→pipeline→candidates→榜单→build→deploy。

## 3. 删除
- `/control` 控制台（serve.py/本地服务/自启动）、`/lab` 实验台、`/calibration` 校准、`/profile` 画像、`/alerts` 预警、`/yearbook` 年度、`/data` 数据包、`/discover`（并入商机榜）。
- 验证/实验/校准/画像/预警/数据包相关 UI、文案、数据与报告；candidates 的 verification/实体验证字段与展示。

## 4. 验收
- 数据：cold-cache determinism（清空翻译缓存后 candidates 冷跑字节=冻结文件、二次一致、--all 0 变化）；validate 20/20；unittest 全绿；候选 200 全部入榜；精选 80 保留。
- 前端：9 路由 zh/en；无验证/实验/校准/画像/预警/年度/数据包/控制台入口或文案（gating 正则 0）；商机榜四窗口 + 全部/精选筛选；i18n/1024/截图。
- 冻结/线上：MANIFEST 19/19；tag deploy+CI success；线上 `/` 与 `/v1.0.0/` 同 hash；旧归档不串台。

## 5. 已知限制
- 中文标题为系统翻译（离线词典；可选 LLM key 提升），个别语句不完美；
- 系统评估为规则评分，不代表商业可行；不承诺盈利；
- 自动源受公开访问/合规限制（101/168，其余人工/API）。
