# v0.7.1 运营文档（OPS）

> 版本：v0.7.1　｜　数据版本：data-v0.7.0　｜　日期：2026-10-23　｜　线上：https://charline88888-ux.github.io/opportunity-radar/

## 1. 本版要点
- 修复「云端每日更新构建失败」：非基准日（如今天无新机会）日榜为空时，前端严格自检不再误报配额不足，每日构建可正常上线。
- 部署并发调整：版本发布与每日数据更新不会互相取消。

## 2. 日常不变
- 本地：双击 `启动机会雷达.bat` → 控制台一键更新/采集/启停每日任务（计划任务已启用，每天 07:00）。
- 线上：每天 06:30 Actions 自动刷新根目录数据；`/vX.Y.Z/` 保留冻结版本。
- 每日没有新机会时，日榜为空是正常现象；周/月/年榜仍由库内数据计算。

## 3. 验收/回滚
- 线上根 = 最新每日数据；`/v0.7.1/` = 冻结版本；回滚打开 `/v0.7.0/` 或旧版目录。
- 如果 Actions 每日更新失败：线上仍保留上一份可用数据；手动触发 `daily-update` 或本地控制台更新后 `publish.ps1` 发版。
