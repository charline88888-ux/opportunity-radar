# v1.2.0 运营文档（OPS）

> 版本：v1.2.0　｜　数据版本：data-v1.2.0　｜　日期：2026-10-23　｜　线上：https://charline88888-ux.github.io/opportunity-radar/

## 1. 怎么看
1. 打开「商机榜」选日/周/月/年；
2. 点候选进详情：先看一句话判断+评分；
3. 展开分区：商业画布、为什么是商机（10 维依据）、竞争与差异、跨市场、时机窗口、条件门槛资金、利润模型、执行方案、来源；
4. 方法论页可查每个维度怎么判断、常见误判。

## 2. 每日自动
Actions 每天 06:30 fetch 101 源 → 候选/评估 → 四窗口榜 → 上线；不需要控制台/验证/实验。

## 3. 边界
系统只做发现与评估，不验证个人能否赚钱、不承诺收益；执行前自行核对来源与本地合规。
